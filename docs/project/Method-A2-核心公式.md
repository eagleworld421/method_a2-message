# Method-A2 核心公式

## 1. 定位与范围

本文定义 Method-A2 的方法符号与核心公式，把问题固定为一条可核对的公式链：仿真侧生成事实响应与反事实响应族，部署侧由观测响应生成全部候选响应，再根据观测与预测响应之间的距离完成故障定位。

本文特别区分两个容易混淆的比较：

- $S^{CF}_{m,k}$ 与 $\widehat S^{CF}_{m,k}$ 的比较是**响应预测监督**，用于衡量模型是否复现了真实的反事实响应；
- $X_m$ 与 $\widehat S^{CF}_{m,k}$ 的比较是**部署候选评分**，用于判断候选 $k$ 是否与当前事实观测相符。

真实反事实响应 $S^{CF}_{m,k}$ 只在训练时作为监督目标使用。本文不把真实反事实响应、真实故障位置、真实故障阻抗或其他评价专用字段加入部署前向。

本文保留 $U_m$ 作为物理生成过程中的不可观测事件上下文，但不规定其内部坐标或具体分解。$U_m$ 不包含故障位置 $K_m^{true}$，也不是部署时可以直接读取的输入。当前实现没有显式的 $\widehat U_m$ 提取模块。

本文只定义符号、公式和信息可见性约束，不宣称方法有效，不包含实验结果，也不改变既有数据接口。所有数值证据在 docs/project/reports/ 下的实验文档中单独记录。

## 2. 核心公式总表

本章按“物理事实生成 → 反事实监督生成 → 部署输入 → 候选响应生成 → 响应监督 → 部署评分 → 最终定位”的顺序给出核心公式。

物理事实生成：

$$X_m=\psi\left(G_m^{true},U_m,K_m^{true}\right)$$

反事实监督生成：

$$S^{CF}_{m,k}=\psi\left(G_m^{true},U_m,\operatorname{do}(K_m=k)\right),\qquad k\in\mathcal K_m$$

部署输入：

$$\left(X_m,G_m^{obs},\mathcal K_m,M_m\right)$$

候选响应生成：

$$\left\{\widehat S^{CF}_{m,k}\right\}_{k\in\mathcal K_m}=D_\theta\left(X_m,G_m^{obs},\mathcal K_m,M_m\right)$$

响应预测监督：

$$L_{\mathrm{resp}}=\frac{1}{Z_{\mathrm{resp}}}\sum_{m}\sum_{k\in\mathcal K_m}d_S\left(S^{CF}_{m,k},\widehat S^{CF}_{m,k}\right)$$

部署响应评分：

$$\widehat R_{m,k}=d_S\left(X_m,\widehat S^{CF}_{m,k}\right)$$

最终定位：

$$\widehat k_m=\arg\min_{k\in\mathcal K_m}\widehat R_{m,k}.$$

各式的职责划分如下：

- 前两式描述仿真侧的物理事实，其中第二式产生训练监督，不属于部署输入；
- 第三、四式描述部署侧的输入和整族候选响应生成；
- 第五式训练响应预测器，要求模型复现所有有效候选的反事实响应；
- 第六式是部署时可直接计算的候选评分；
- 第七式在有效候选中选择观测与预测响应距离最小的位置。候选排序完全由反事实响应预测及其距离决定。

## 3. 符号定义

事件与状态：

- $m$：事件样本索引。
- $G_m^{true}$：生成该样本的真实电网拓扑。当前正式范围固定为单一拓扑，因而样本间相同。
- $G_m^{obs}$：部署时提供给模型的拓扑。当前等于 $G_m^{true}$；部分观测与错误拓扑属于后续场景。
- $U_m$：事件的不可观测上下文。本文只把它作为物理生成公式中的概念变量，不规定其内部坐标、具体组成或直接标签，也不把它作为当前模型的显式前向输入。
- $K_m^{true}$：该事件真实故障母线，只用于生成目标与离线评价。
- $k$：候选故障母线假设。
- $\mathcal K_m$：事件 $m$ 的有效候选集合，由该事件的候选掩码与候选轴共同确定。掩码为 1 的候选参与本次事件的训练与评价。
- $\operatorname{do}(K_m=k)$：把故障位置干预为 $k$，其余条件保持不变。
- $\psi$：物理响应生成过程。它的实现是潮流或短路仿真，不是可学习模块。
- $M_m$：部署时的观测掩码，表示哪些节点、相别和时间通道可用。候选有效性由 $\mathcal K_m$ 给出。

响应与模型：

- $X_m$：第 $m$ 个事件的事实观测窗口。当前由故障前片段建立基准的全节点三相复电压响应构成。
- $S^{CF}_{m,k}$：在同一事件条件下把故障位置干预为 $k$ 时的真实物理响应。
- $\widehat S^{CF}_{m,k}$：模型对候选 $k$ 输出的反事实响应预测。
- $D_\theta$：候选响应生成器，参数为 $\theta$，一次前向输出整族候选响应。
- $e_k$：候选 $k$ 的部署可见描述，例如候选位置的拓扑或电气特征。

监督与评分：

- $d_S$：响应空间距离，定义见第 4 节。
- $\widehat R_{m,k}$：由模型输出得到的部署期候选评分。
- $\widehat k_m$：输出的故障母线估计。

## 4. 响应距离 $d_S$ 的定义

$d_S$ 必须明确节点、相别、时间与缺失掩码的计算规则，不能默认为未定义的相似度。本文采用带掩码的归一化平方误差：

$$d_S\left(X,\widehat S\right)=\frac{\sum_{n=1}^{N}\sum_{t=1}^{T}\sum_{f=1}^{F}M_{n,t,f}\frac{\left(X_{n,t,f}-\widehat S_{n,t,f}\right)^2}{s_{n,f}^2+10^{-8}}}{\sum_{n=1}^{N}\sum_{t=1}^{T}\sum_{f=1}^{F}M_{n,t,f}}$$

其中 $s_{n,f}$ 是训练集保存的节点尺度量，只作数值归一化，不是节点重要性或故障影响权重。

分母只含有效掩码总和，权重不进入分母。当前全节点全通道观测时，分母为 $N\cdot T\cdot F$。若另按活跃相数或逐节点通道数归一，那是另一种口径，必须单独声明，不得与本文的 $d_S$ 混用。

量纲必须保持一致：$d_S$ 是平方量（加权 MSE），其平方根才满足三角不等式。同一篇文档中不得把 $d_S$ 和 $\sqrt{d_S}$ 混称为同一种距离；候选间隔、误差比例和权重定义必须注明所采用的口径。

## 5. 训练目标与部署评分

当前方法只使用真实反事实响应训练候选响应生成器：

$$L_{\mathrm{resp}}=\frac{1}{Z_{\mathrm{resp}}}\sum_{m}\sum_{k\in\mathcal K_m}d_S\left(S^{CF}_{m,k},\widehat S^{CF}_{m,k}\right).$$

部署时不使用真实反事实响应，而是计算事实观测与各候选预测响应之间的距离：

$$\widehat R_{m,k}=d_S\left(X_m,\widehat S^{CF}_{m,k}\right).$$

当前仿真数据满足：

$$X_m=S^{CF}_{m,K_m^{true}}.$$

因此理想情况下真实候选的观测一致性评分最小。这个事实只用于构造训练数据和离线评价，不把 $K_m^{true}$ 作为模型输入。

必须区分以下两种用途：

- $d_S(S^{CF}_{m,k},\widehat S^{CF}_{m,k})$ 是响应重构误差，用于训练 $D_\theta$；
- $d_S(X_m,\widehat S^{CF}_{m,k})$ 是部署时实际计算的候选评分，用于最终定位。

真实 $S^{CF}_{m,k}$ 不进入部署前向，候选排序直接由观测与预测响应之间的距离完成。

## 6. 候选集合与最终定位口径

当前候选轴含 $N+1$ 项：索引 $0$ 至 $N-1$ 为故障母线候选，最后一项为正常候选。训练输出和响应监督都使用事件有效掩码 $\mathcal K_m$，正常候选也可以作为候选族成员参与响应生成与检测判断。

定位排名与检测判断在评价上严格区分：

- 定位排名与 Top-K 只在故障母线候选上进行，正常候选不并入定位排名；
- 正常候选的评分单独用于检测判断，不与定位指标混合；
- 本文没有规定正常候选对应的正式检测阈值、拒识阈值或不确定性校准方法；因此当前公式只能定义候选响应排序和定位，不能单独宣称已经完成故障检测与证据不足时的拒识；
- 候选轴语义由候选特征表中的无故障指示位与生成代码共同确定，且已有断言保证正常候选位于最后。

候选列表的排列不应改变诊断含义。对任意候选置换 $\pi$，候选特征、响应输出和候选掩码应按同一置换同步重排；观测 $X_m$ 与拓扑节点语义不随候选列表顺序改变。这一性质应作为实现测试和实验审计项，而不是依赖候选索引的额外输入。

## 7. 公式与既有文档及数据的对应关系

公式链中各量的来源可以逐条指认：

- $X_m$、$S^{CF}_{m,k}$、$M_m$ 与候选轴语义由《Method-A1-PI响应数据集契约与数据生成流程》规定的事件数组字段与可见性分类给出；
- 前两式描述的生成路径即该契约中的数据生成流程，其实现是仿真脚本而非可学习模块；
- 第三式的输入全部属于部署可见量，其中 $\mathcal K_m$ 由候选掩码与候选特征表给出；
- 第四式要求模型一次前向输出全部候选响应，不能通过把候选逐个串行地依赖于前一个候选来改变同一事件的共享输入；
- 第五式使用真实反事实响应训练响应生成器；
- 第六式只使用观测与模型输出，是部署时实际计算的候选距离；
- 所有训练与推理公式都不把 $U_m$、$K_m^{true}$ 或真实故障阻抗作为部署输入。

由此得到一条对研究问题至关重要的性质：**真实反事实响应只提供训练期的物理教师，部署侧候选排序必须由观测响应和预测响应之间的距离产生。**

## 8. 问题陈述

把前述公式合起来，本文要研究的问题可以写成一句：

> 给定只含部署可见输入的映射 $D_\theta$，以及每个事件仅有一个事实观测 $X_m$，如何使模型生成的候选响应族在响应空间中保持足够的物理结构，并使观测与预测响应之间的距离正确排序，最终让 $\widehat k_m$ 等于 $K_m^{true}$。

其中，响应预测误差和候选排序误差是两个不同层次的问题。高质量的 $S^{CF}_{m,k}$ 重构并不自动保证 $X_m$ 与 $\widehat S^{CF}_{m,k}$ 的候选排序正确，因此二者必须分别报告并通过消融实验验证。

本文与《研究目标与总体思路》的关系是局部方法分支关系：本文形式化了“生成候选反事实响应并通过观测一致性完成候选排序”的主链。本文尚未定义拒识规则或不确定性校准，因此不能把本公式链单独解释为总体研究目标的完整实现。

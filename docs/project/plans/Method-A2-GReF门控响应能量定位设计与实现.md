# Method-A2 GReF 门控响应能量定位设计与实现

## 1. 名称、目标与证据边界

- 方法名称：GReF，英文全称 Gated Response-energy Fault Localization，中文名称为可辨识性门控响应能量定位。
- 制定日期：2026-11-03。
- 任务标识：GREF-001。
- 定位：Method-A2 内的独立实验路径，复用 Node Marker 响应骨干，不覆盖既有模型、训练入口或产物。
- 目标：使部署候选评分完全由预测反事实响应与事实观测的差异产生，并使定位监督直接更新响应解码器。
- 本次范围：完成设计、代码、契约测试与小规模链路验证；不自动启动 IEEE37 的多种子正式训练，不宣称准确率改善。
- 分支约定：用户已明确允许从当前开发基础创建 `agent/GREF-001-response-energy`，保留既有未提交修改。

依据为[核心公式](../Method-A2-核心公式.md)、[Top-1 定位优化综述](Method-A2-Top1定位优化问题实验与计划综述.md)与[旧能量定位设计](Method-A2-反事实能量定位loc设计方案.md)。本实验采用响应能量上的门控交叉熵，不采用旧设计中的全列表 KL 或有界校准残差；这是已获用户同意的独立实验取舍，不改写正式核心公式。

## 2. 统一响应坐标与部署评分

先按 `group_id` 划定最终训练、验证、测试集合，再仅用最终训练样本的有效候选响应拟合逐节点、逐通道均值和标准差，统计轴为样本、候选和时间。可用掩码进入统计，标准差小于数值下界的维度以 1 替代。

既有数据已经标准化时，在其现有坐标中重新拟合训练侧仿射变换，对观测和全部目标使用同一变换。这在原仿射标准化可逆且忽略浮点舍入时等价于从原始数据拟合最终训练尺度，不再次除以旧 `feature_scaler.std`。保存变换参数、拟合索引和数据来源，禁止覆盖原数据。新评分与历史重复归一化评分的数值不能直接比较。

记最终标准化后的事实观测、真实响应与预测响应为 $\bar X_m$、$\bar S^{CF}_{m,k}$、$\widehat{\bar S}^{CF}_{m,k}$。设观测掩码为 $M_{m,n,t,f}$，有效候选掩码为 $A_{m,k}$，则

$$e_{m,k}=\frac{\sum_{n,t,f}M_{m,n,t,f}(\bar X_{m,n,t,f}-\widehat{\bar S}^{CF}_{m,k,n,t,f})^2}{\sum_{n,t,f}M_{m,n,t,f}}.$$

$$\widehat k_m=\arg\min_{k\in\mathcal K_m^{fault},\,A_{m,k}=1}e_{m,k}.$$

有效观测数为零时拒绝计算。正常候选保留响应和能量输出，但不进入故障定位排名。距离计算没有可学习参数；第一版没有自由评分头、校准残差、异方差头或额外距离回归。

编码器和解码器沿用现有 Node Marker 骨干，因此事件级均值池化仍存在于响应生成路径；禁止的是其绕过预测响应直接产生候选评分。旧 `score_head` 在新类中替换为无参数恒等层以兼容原前向接口，其中间输出被响应能量替换，不存在可训练的旧评分头参数。

## 3. 真实响应门控与定位损失

训练期使用同一距离计算物理教师能量与真实位置间隔：

$$e^*_{m,k}=D(\bar X_m,\bar S^{CF}_{m,k}),\qquad \Delta_m^*=\min_{k\ne y_m,\,k\in\mathcal K_m^{fault},\,A_{m,k}=1}e^*_{m,k}-e^*_{m,y_m}.$$

$$w_m=\mathbf1[\Delta_m^*>\epsilon_m]\frac{\Delta_m^*-\epsilon_m}{\Delta_m^*+\eta}.$$

正常样本权重为零。不存在有效错误故障候选时，不提供定位监督。真实位置越界或被屏蔽时拒绝训练。物理教师和权重均停止梯度；验证和测试的门控仅用于离线诊断，不控制部署预测。

首版入口使用显式给出的全局正容差 `energy_tolerance` 及非空 `tolerance_source`；损失接口允许逐事件容差。容差必须与最终标准化能量同单位，应依据训练侧重复求解、数值精度或实际噪声测量确定。软件测试中的合成容差仅验证实现，不构成物理标定。不得默认为零，也不得由当前模型误差设置门槛以排除未学会的样本。

$$p_{m,k}=\frac{\exp(-e_{m,k}/T)}{\sum_{u\in\mathcal K_m^{fault},\,A_{m,u}=1}\exp(-e_{m,u}/T)},\qquad L_{loc}=-\frac{\sum_{m\in\mathcal B_f}w_m\log p_{m,y_m}}{\sum_{m\in\mathcal B_f}w_m+\eta}.$$

温度 $T>0$ 是显式固定参数；取值范围应依据训练侧教师间隔确定，最终取值只能通过验证集选择。温度不影响部署排序，训练概率不作为已校准置信度。若某批次没有有效监督，定位项返回可微零值；若整个训练集的有效监督为零，入口拒绝以 GReF 定位训练名义继续。

## 4. 全候选重构与联合目标

$$L_{family}=\frac{\sum_{m,k,n,t,f}A_{m,k}M_{m,n,t,f}\operatorname{SmoothL1}(\widehat{\bar S}^{CF}_{m,k,n,t,f}-\bar S^{CF}_{m,k,n,t,f})}{\sum_{m,k,n,t,f}A_{m,k}M_{m,n,t,f}}.$$

$$L=L_{loc}+\lambda_{family}L_{family},\qquad\lambda_{family}>0.$$

定位未获门控许可的样本仍参与全候选重构，正常候选亦参与重构。默认工程起点可沿用 `lambda_family=0.1`，但该数值不代表已完成权重标定。第一版不加入 `rank`、`list`、`value`、`gap` 或 `pair`；共享表示一致性留待独立消融。

## 5. 数据、训练与产物契约

- 数据只读，要求现有 `[B,N,T,F]` 观测、`[B,N+1,N,T,F]` 签名库、合法 `group_id`、候选与观测掩码，以及候选轴一致的位置标签。
- 使用既有 `split_by_group` 生成三段分组划分；不得使用测试集合选择轮次、温度、容差或重构权重。
- 使用内存映射和分批统计，避免复制完整 IEEE37 签名库。
- 每次评价先切换评价模式。按验证集严格 Top-1 最大、重构损失最小的顺序选模，恢复最佳状态后仅作最终测试。
- 评价包含全部故障事件，包括门控关闭事件；同时报告按节点、电阻及门控覆盖分层的指标。不能用可靠子集的结果替代完整测试结果。
- 源代码位于 `code/method-a2/src/gref/`，入口为 `code/method-a2/scripts/train_gref.py`，测试位于 `code/method-a2/tests/test_gref.py`。
- 新运行输出限定在 `code/method-a2/output/gref/<run-id>/`，日志位于 `code/method-a2/logs/<run-id>/`；已有输出目录拒绝覆盖。
- 最小产物包括 `config.json`、`normalization.npz`、`split.npz`、`dataset_audit.json`、`gate_audit.json`、逐轮训练历史、最佳 `model.pt`、验证与测试指标、测试 `predictions.npz`、实际执行的反捷径审计及单次 `report.md`。
- 保存软件版本、代码文件摘要、随机种子、超参数、数据路径、输入坐标及归一化定义。测试产物必须同时保存评分、观测、响应目标、预测响应、位置、候选掩码与样本索引，支持离线复算。
- 复用现有 `ProgressWriter`，对标准化统计、数据审计、训练批次、验证与最终写出持续记录；仅在全部产物写出后记录 `end`。

## 6. 验收与实验限制

- 验证手算能量、有效掩码分母及正常候选隔离。
- 验证教师间隔、容差边界、教师标签冲突、全门控关闭、全正常批次和非法真实候选。
- 仅反传定位项，验证响应输出层和共享编码器均获得非零梯度；验证不存在可训练的自由评分头。
- 验证候选同步置换、响应置换评分跟随，以及候选无关响应产生并列分数。
- 用训练集合统计不随验证或测试值改变的测试，防止预处理泄漏。
- 运行合成数据端到端冒烟，检查选模、保存、复算和进度终态；合成结果不得作为物理实验结果。
- 正式实验至少三种子，比较统一坐标下的响应距离基线、无门控消融与 GReF；旧评分头作为性能参照。
- 正式训练还须分析定位与重构在共享编码器、响应解码器上的梯度余弦及实际优化器更新；接口测试不替代上述实验。
- 本方案保证评分经预测响应产生，但响应生成器仍可能学习任务性编码。必须结合物理重构质量与响应屏蔽实验评估，不能仅凭结构或非零梯度宣称因果机制成立。
- 小间距和响应预测误差仍可能限制严格 Top-1，不保证超过旧评分头。当前未完成 IEEE37 容差标定、温度选参及多种子重训。

## 7. 实现状态与调用方式

截至 2026-11-03，已实现独立模型、门控损失、只读数据加载、训练侧标准化、训练与评价入口；新增 GReF 测试 19 项，与 Node Marker、准确率升级和进度模块相关测试合计 49 项通过。测试验证软件契约，不构成物理实验结论。

在 `code/method-a2/` 目录执行 `python scripts/train_gref.py --help` 可查看参数。正式调用必须显式提供以下参数：

- `--data-dir`：待训练的数据目录，例如 `data/s0-ieee37-r0p01-20-loguniform`。
- `--output-dir`：全新输出目录，例如 `output/gref/ieee37-a-seed342`。
- `--energy-tolerance`：在本方案最终标准化能量坐标中测量的正容差。
- `--tolerance-source`：容差的测量产物路径或可追溯说明。
- `--temperature`：根据训练侧尺度及验证集选择并冻结的正温度。

其余参数包括 `--epochs`、`--batch-size`、`--lambda-family`、`--learning-rate`、`--seed`、`--val-ratio`、`--test-ratio` 与 `--device`。`--smoke` 仅为输出增加冒烟标记，不自动缩减训练预算；软件验证需显式指定小轮数。

已通过独立命令行入口执行两轮合成数据训练，交付目录为 `code/method-a2/output/gref/implementation-smoke-20261103-6bc8cd58/`。其 `config.json` 明确记录 `smoke=true`，容差来源为 `synthetic-software-check-only`；该目录中的容差、温度、权重与性能均不得作为 IEEE37 的物理标定或正式实验结果。正式实验所需的梯度余弦、Adam 更新分析和多种子比较仍按第 6 节另行执行。

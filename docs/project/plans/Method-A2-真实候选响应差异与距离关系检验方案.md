# 真实候选响应差异与距离关系检验方案

## 检验对象与成功条件

固定参数族 $m$ 的负荷、A 相接地故障类型及故障电阻，改变故障位置。使用数据集真实签名 $S_m(k)$，定义 $D_m(f,k)=\operatorname{mean}[(S_m(f)-S_m(k))^2]$，不读取模型权重、预测响应或模型评分。正常候选和正常事实不参与故障距离检验。

主分析覆盖两套 IEEE37 数据各 40 个族、1520 个事实故障点；另单列历史 GReF 测试的六个参数族 1、3、24、26、28、38，每组 228 个事件。成功条件为同族全部响应库一致、同族条件与故障位置完整、观测与真实候选签名一致、对角差异为零、两两响应差异对称、物理尺度与距离来源可追溯、全部事件统计与可视化完成。

## 配对及尺度

审计所有故障行，确认同族 38 个响应库逐元素一致、38 个位置各出现一次、故障电阻及类型相同、观测和候选掩码完整。保存对观测与库内真实签名的最大差异；若不为零，应区分观测口径与真实响应口径，不得静默合并。

数据生成使用各母线电压标幺相量构建实虚部窗口，随后以训练集六通道均值及标准差作全局标准化。因此主分析通过 `feature_scaler.npz` 还原物理标幺差异，计算时直接以标准化响应之差乘通道标准差，均值项抵消。此尺度不使用模型的逐节点归一化参数。存储标准化坐标下的均方差作为敏感性对照。

位置距离复用已审计的跳数、米制线路长度及统一 1 MVA 基准下的无零序模态阻抗路径；输入矩阵和母线序列均从前次审计产物读取，并核验与当前图连接一致。阻抗是静态代理，不视为精确单相接地回路阻抗。

## 判据与图件

- 路径判据沿树的外向边检查增量。数值容差采用与量值同比例的 $16\epsilon_{32}\max D$，仅在全零向量时使用浮点最小正值；不沿用模型审计的固定 $10^{-8}$ 下限，以免吞没真实的小响应差异。另用事件范围的 0.1%、1%、5% 检查平台阈值敏感性。主要现象统计使用 1% 事件范围，包含严格增长、非递减含平台、存在下降的互斥分类，平台和同跳数分支差异允许重叠。
- 远近顺序仅在错误候选间检查，排除真实点；等距对不算严格远近对。按三种距离分别计算逆序比例、Spearman 和 Pearson；同时报告每族统计，避免把同族 38 个故障点当成独立物理条件重复。
- 区分“沿路径非递减”“任意分支间按距离有序”和“总体正相关”，不以相关代替单调性。
- 对实际存在的严格增长、非递减含平台、平台、下降、分支差异，各确定性选取至多 3 个案例，展示拓扑数值及三种归一化距离曲线；不存在或不足 3 例时如实记录，不制造案例。
- 主输出为逐事件统计、全候选数值、参数审计、分类占比及图件，最终归档至 `code/method-a2/output/oracle-distance/ieee37-20261103/final/`，上级目录保留首次分析。另剔除低压末端 775 的事实与候选作敏感性对照，保持观测节点不变并重新计算事件范围容差。保留全范围图，同时放大主体候选以避免极值遮蔽变化；放大图不改变完整候选统计。

距离来源见[电气加权距离报告](../reports/Method-A2-GReF电气加权距离分析报告.md)，候选响应及模型响应必须分别命名。此检验能够判断真实数据是否具有简单距离排序结构，不能单凭该结构证明模型误差的全部来源。

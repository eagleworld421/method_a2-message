# GReF IEEE37 首轮训练与测试执行计划

## 1. 范围与预算

- 执行日期：2026-11-03。
- 任务标识：GREF-002。
- 依据：用户要求对既有数据集进行训练和测试；方法采用 [GReF 设计](Method-A2-GReF门控响应能量定位设计与实现.md)。
- 数据集 A：`code/method-a2/data/s0-ieee37-r0p01-20-loguniform/`。
- 数据集 B：`code/method-a2/data/s0-ieee37-r10-100-loguniform/`。
- 本次为首轮训练验证，沿用历史种子 342、批大小 64、学习率 0.001、重构权重 0.1、最终训练预算每组 200 轮。训练设备为 NVIDIA GeForce GTX 1660 SUPER，使用 CUDA。
- 按种子 342 和 `group_id` 重建划分，各组训练 2280、验证 228、测试 228；验证和测试均为故障样本。
- 本轮不执行多种子有效性验证、无门控消融或噪声鲁棒性实验，不能代替完整方法验证。

## 2. 数值容差标定

仅最终训练索引参与标准化和容差标定。对每条训练故障事件，确定真实候选及最近错误候选，计算原存储 float32 数据在上下一个可表示值处的一个 ULP 扰动幅度，将其传播至最终标准化坐标；叠加实测 float32 仿射计算相对 float64 的舍入差异。

若标准化响应差为 $d$、两侧合计坐标扰动预算为 $b$，平方能量变化预算采用 $\operatorname{mean}(2|d|b+b^2)$，另计真实候选的扰动预算与实测能量规约舍入差异。将训练侧全部最近错误候选的最大预算与实测 CPU/CUDA 间隔差异最大值比较，取二者较大值为全局正容差。

- A 容差：`2.231209336901537e-6`；训练故障样本门控覆盖率约 98.97%。
- B 容差：`2.3069154875252437e-6`；训练故障样本门控覆盖率约 70.49%。
- 解释边界：这是干净 S0 数据的浮点数值敏感性预算，只审计最近错误候选，不是所有候选的严格认证上界，也不是仿真误差或传感器噪声标定。
- 标定证据：`code/method-a2/output/gref/ieee37-seed342-20261103-calibration/calibration-a.json` 与同目录 `calibration-b.json`，包含逐训练事件读数及最终训练归一化参数。

## 3. 温度预选与冻结

以训练侧通过容差门的真实候选间隔中位数 $q$ 为尺度，预登记温度集合 $\{0.3q,q,3q\}$。

- A 温度集合：`0.0012815295718610286`、`0.004271765239536762`、`0.012815295718610287`。
- B 温度集合：`8.550644088245462e-6`、`2.850214696081821e-5`、`8.550644088245463e-5`。
- 每个候选温度从同一种子重新初始化，训练 20 轮，仅评价验证集，不计算测试指标。
- 按预选阶段最佳验证 Top-1 最大、对应验证重构损失最小的顺序选择温度；完全相同时按预登记顺序选择。
- 每组选择后冻结温度，从头初始化完成 200 轮训练，不延续预选模型或优化器状态。
- 该有限预算预选不能保证获得充分收敛下的最优温度，不依据最终测试结果扩展温度集合。

## 4. 选模、测试与交付

- 最终训练每轮使用评价模式计算验证指标，按验证 Top-1 最大、重构损失最小选模。
- 恢复最佳模型后对完整测试集作最终评价，不按门控筛除测试事件。
- 核验预测响应距离与保存评分一致、评分复算 Top-K 与指标文件一致、分组划分无重叠、候选置换通过和响应均值屏蔽后性能变化。
- 两组原始运行交付目录分别为 `code/method-a2/output/gref/ieee37-a-seed342-20261103/` 与 `code/method-a2/output/gref/ieee37-b-seed342-20261103/`；既有输出不覆盖。
- 预选记录归入标定目录，进度按各运行标识保存至 `code/method-a2/logs/`。
- 单次摘要和复核结果归入对应 `output/`，若另写跨运行正式结论则归入 `docs/project/reports/` 并登记索引。
- 单种子、6 个独立测试故障族、干净完整观测和 CUDA 非严格确定性是本轮结论边界；不得直接宣称跨电阻范围迁移或超越历史独立评分头。

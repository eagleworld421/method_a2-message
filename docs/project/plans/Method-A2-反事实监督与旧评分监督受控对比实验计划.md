# Method-A2 反事实监督与旧评分监督受控对比实验计划

## 1. 实验问题与因果边界

已有结果显示，旧直接评分路径在 `s0-lg-run3` 上的定位 Top-K 高于新的反事实候选评分路径。新的评分路径使用真实反事实响应构造候选距离，再通过列表级目标训练候选评分；旧路径使用真实故障位置的分类目标和以真实位置为正样本的候选排序目标。两条路径此前同时存在模型接口、评分头、损失形式和训练实现差异，因此不能直接把 Top-K 差异归因于反事实监督本身。

本计划只回答一个受控问题：

> 在完全相同的反事实评分模型和训练条件下，把候选评分监督从旧的真实位置定位/排序目标替换为真实反事实距离列表目标，是否会导致定位 Top-K 下降？

响应重构目标在所有配置中保持不变，作为共同背景目标。这样可以把“候选评分监督的替换效应”与“预测响应分支是否存在”分开。本计划不把真实反事实距离与预测反事实距离混用；真实距离只用于训练监督和物理排序评价，预测距离只作为独立诊断指标。

## 2. 受控变量与实验对象

所有配置必须固定以下条件：

- 数据集为 `code/method-a2/data/s0-lg-run3/`，使用同一训练、验证和测试索引；
- 使用同一个 `CounterfactualScoringModel` 结构，包括同一共享编码器、响应解码器、候选条件输入和独立评分头；
- 使用同一批大小、学习率、训练轮数、验证集选模规则、候选掩码和距离实现；
- 使用同一距离尺度计算方式，即只由训练集非零真实候选距离确定；
- 使用随机种子 `342、343、344`，每个种子从相同模型初始化流程开始；
- 不改变响应重构目标 `family` 及其权重；
- 不引入新的损失项，不改变既有 `loc`、`rank`、`list` 的定义，仅把它们接到同一评分输出上；
- 不修改旧训练脚本、旧损失函数和既有输出目录，所有代码与运行结果写入新的受控实验路径。

实验模型的候选评分方向统一为“分数越小表示候选越接近事实观测”。旧定位分类目标只负责把真实位置推向最低分，旧排序目标和反事实列表目标均按这一方向实现。任何方向相反的实现都必须在运行前通过单元测试排除。

## 3. 监督配置

每个配置都包含权重为 0.1 的 `family`，候选评分目标按下列方式替换。

### 3.1 旧评分监督配置

候选评分目标为：

- `loc`：真实位置交叉熵，故障候选掩码只保留可定位候选；
- `rank`：以真实位置为正样本的候选排序损失，权重沿用旧路径的 0.1。

总目标记为 `family + loc + rank`。该配置是同一反事实评分模型上的旧监督对照，不直接把旧模型的历史结果当作因果对照。

### 3.2 反事实列表监督配置

候选评分目标为 `list`：由真实反事实距离构造软候选分布的列表级 KL，权重为 1.0。总目标记为 `family + list`；温度、距离尺度和候选有效掩码固定为当前反事实评分路径的实现。

### 3.3 反事实标定扩展配置

为区分“列表监督替换效应”和“额外数值/间距目标造成的干扰”，保留两组次级配置：

- `list_value`：`family + list + value`；
- `list_gap`：`family + list + gap`。

这两组只用于解释当前反事实路径中 Top-K 下降是否由 `value` 或 `gap` 的梯度主导进一步放大，不能替代 `family + list` 与 `family + loc + rank` 的核心比较。

## 4. 执行流程

### 4.1 数据与实现核验

训练前逐项核验：

- 同一输入批次经过各配置时，模型参数数量和输出形状完全一致；
- `loc`、`rank`、`list` 的分数方向一致，真实位置在人工评分样例中获得最低目标分数；
- `family` 在所有配置中的数值和梯度路径相同；
- 各配置只改变候选评分目标的实际权重，未改变前向图、数据顺序和验证选模逻辑；
- 真实距离由 `X_obs` 与 `signature_bank` 计算，预测距离由 `X_obs` 与模型输出响应计算，二者分别落盘。

### 4.2 训练与选模

每个配置、每个种子训练 200 轮。每轮保存训练损失，验证阶段记录候选评分损失、响应重构损失和 Top-1/Top-3/Top-5。以验证集 Top-1 选择最佳轮次；若 Top-1 相同，依次以验证集 Top-3、响应重构损失和较早轮次作为确定性平局规则。最佳模型只在测试集上评估一次。

测试结果必须同时保存模型输出评分、真实距离、预测距离和候选排序，避免只保存聚合指标而无法复核排序差异。

### 4.3 梯度记录

在第 1、100、200 轮的固定训练探针批次上，分别计算每个目标的实际加权梯度，并按共享编码器、响应解码器和评分头分组保存：梯度范数和 RMS、梯度范数占比、目标间梯度余弦相似度、各目标对合成梯度的投影，以及被禁用目标的零梯度核验。梯度统计只描述当前目标的局部作用，不直接等价于 Top-K 贡献；若条件允许，附加记录 Adam 预条件后的参数更新范数。

## 5. 评价指标

主要定位指标为测试集 Top-1、Top-3、Top-5 和平均名次。报告每个种子的结果、三种子均值、标准差以及相对旧监督配置的差值。核心比较为：

\[
\Delta_{\mathrm{CF-old}}^{(K)}
=\operatorname{TopK}_{\mathrm{family+list}}
-\operatorname{TopK}_{\mathrm{family+loc+rank}}.
\]

同时保存并计算评分与真实反事实距离的 Spearman 相关、候选对一致率、真实候选距离的最小值/p05/中位数/p95 间距、评分间距与真实距离间距的相关性、软列表目标熵，以及真实位置与第二名候选的评分 margin。严格全序一致率只作为补充指标，候选距离接近或存在并列时不单独据此判定物理排序是否成功。

响应侧记录 `family` 重构损失、事实候选的预测距离、预测距离与真实距离的相关性，以及真实候选与预测候选排序的一致性；该组指标用于判断 Top-K 下降是否伴随响应预测恶化，不能替代定位指标。

## 6. 预先登记的判定规则

若在同一模型和同一训练流程下，`family+list` 的 Top-K 均值低于 `family+loc+rank`，下降方向在至少两个种子上保持一致，响应重构损失没有同步恶化到足以解释全部差异，且 `family+list` 的真实距离相关性不低但定位 margin 或列表熵显示候选间物理差距不足以形成稳定第一名，则认为反事实列表监督是 Top-K 下降的主要候选原因。结论只能表述为“当前物理距离列表监督与离散根因定位目标存在错配”，不能表述为“反事实响应监督本身无效”。

若两种监督在同一模型上的 Top-K 差异处于种子波动范围内，而历史旧路径仍明显更高，则继续检查模型结构、评分头实现、数据版本、损失方向和选模规则。若三种子方向不一致，停止强因果表述，转入权重和温度敏感性分析。

若 `list_value` 或 `list_gap` 相对 `family+list` 进一步下降，同时新增目标在共享编码器或评分头上的梯度占比超过 `list`，则判定新增目标改变了优化方向。只有当它们提高 Top-K 且不牺牲真实距离相关性，才考虑保留为有效辅助监督。

## 7. 产物与边界

新增代码建议置于 `code/method-a2/src/counterfactual_scoring/controlled_losses.py`、`code/method-a2/scripts/run_controlled_scoring_comparison.py` 和 `code/method-a2/tests/test_controlled_scoring_comparison.py`。运行产物置于 `code/method-a2/output/counterfactual-score-controlled-s0-lg-run3/`，按配置和种子保存配置、指标、梯度、逐样本预测、模型和日志；正式结论归档到 `docs/project/reports/`。

当前真实候选距离中位间距约为 `1.585355×10^-5`，相对于距离尺度较小。若列表目标熵接近均匀分布，应解释为监督分辨率不足，而不能简单归因于模型容量不足。即使旧监督配置在同一模型上显著优于反事实列表配置，也只能说明当前距离口径、温度、尺度或列表损失与 Top-K 定位目标尚未对齐。

本计划不包含新的物理数据生成、不改变候选集合、不调整拓扑、不增加预测反事实距离诊断损失，也不覆盖缺少测量条件的场景。

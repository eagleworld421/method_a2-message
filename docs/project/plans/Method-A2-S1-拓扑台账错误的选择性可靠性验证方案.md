# Method-A2 S1 拓扑台账错误的选择性可靠性验证方案

日期：2026-11-05

文档定位：实验执行前的方案与设计文档；不含新实验结果，不修改正式核心公式，不新增模型模块。

## 1. 问题与主张

当前 S1 实验的做法是：保持 S0 数据、观测与物理签名不变，仅在推理时屏蔽 1 至 3 条无向边，报告 Top-1／Top-3／Top-5 的相对变化。该做法能够描述“输入拓扑删边后平均排序准确率如何变化”，但不能回答三个更关键的问题：

- 模型能否发现当前拓扑下没有任何候选能够解释观测；
- 模型是否会把拓扑台账错误误判为某个故障候选；
- 模型能否在证据不足时拒识或提示核查拓扑。

原因有两点。第一，平均 Top-K 会把“高置信错误”和“可接受的拒识”混在一起；即使平均值下降很小，也不能排除错误集中在高置信样本。第二，平均准确率不下降也可能意味着模型根本没有使用拓扑，而不是模型对拓扑错误具有鲁棒性。

因此，本文将 S1 的验证主张从“拓扑变化后平均准确率不显著下降”改为“选择性可靠”：

> 在可检测的拓扑台账错误下，模型要么给出正确位置，要么拒识或提示核查拓扑；它不会以高置信度把拓扑错误误判为某个故障候选。

该主张与《研究目标与总体思路》中“稳定、可比较、能够识别证据不足”的可靠性定义一致，并且可以使用现有模型输出度量，不需要新增神经网络模块。

## 2. 术语、范围与当前证据

### 2.1 拓扑台账错误

拓扑台账错误指部署时提供给模型的拓扑记录 $G^{obs}$ 与真实物理拓扑 $G^{true}$ 不一致，而故障的物理响应、反事实监督与评价标签仍由 $G^{true}$ 生成。其本质是信息错误，不是物理拓扑变化。典型形式包括边缺失、边虚增、连接错接、开关状态错误、相别错误、母线合并或拆分，以及由这些错误导致的候选轴变化。

《Method-A2-核心公式》已将 $G^{true}$ 与 $G^{obs}$ 区分，并说明当前正式范围二者相等；S1 正是二者分离的场景。

### 2.2 当前 S1 的定位

当前 S1 属于“边缺失”子类，本文记为 S1-EN。其构造是：物理响应与签名不变，仅将模型输入图中的若干无向边屏蔽。该构造符合“台账漏录或台账断开、实际存在或闭合”的语义，因此属于拓扑台账错误，但只覆盖一个方向、一种错误类型和随机删边一种结构。

当前 S1 结果对应 candidate-score 运行，不是当前 GReF 主线；以 `s0-lg-run3` 为例，测试集为 96 条故障事件、6 个故障族，单一种子，没有 Oracle、拒识、误归因或可检测性分析。原始执行脚本未归档。因此，现有结果只能作为描述性观察，不能作为可靠性证据。

### 2.3 本方案的范围

本方案首先限定在 S1-EN，使用冻结的当前 GReF 模型，不重新训练，不新增模型模块。边虚增、开关状态反转、连接错接、相别错误与候选轴变化放在第二阶段。本文不主张覆盖全部拓扑台账错误，也不主张跨拓扑、真实量测噪声、多故障或 S4 高阻条件下的结论。

需要特别指出：当前构图代码 `code/method-a2/src/data_generation/opendss_sim.py` 的 `_load_topology` 遍历全部 Lines 与 Transformers，未读取开关分合状态；因此 `edge_index` 更接近线路／变压器全集，不一定是实际带电拓扑。`code/method-a2/src/data_generation/topology.py` 中的 `inject_topology_error` 目前没有调用者，且 `flip` 分支实际等价于删除。S1-EN 的“删边”语义必须建立在显式 $G^{true}$ 上：只有 $G^{true}$ 中存在的边被 $G^{obs}$ 漏掉，才是台账漏录；删除本来就不存在的边不构成漏录错误。该前提应在实验配置中逐条核对。

## 3. 文献如何证明同类问题

### 3.1 模型基诊断与一致性诊断

Reiter 与 de Kleer、Williams 的工作把诊断定义为：使系统模型与观测一致的最小异常组件集合。如果不存在任何一致的诊断，则说明模型本身或拓扑假设不成立，而不是某个组件故障。这是“没有任何候选能解释观测”在逻辑上的正式来源。其证明方式是形式化定义、最小诊断定理与小规模例子，不依赖统计数据。

对本文的启示是：S1 需要一个显式的一致性谓词和“无诊断”结果；但经典方法假设模型已知，而本文的候选响应预测器是学习代理，因此必须把一致性谓词实现为可校准的残差检验，不能直接套用定理。

### 3.2 状态估计中的拓扑错误检测与辨识

Soltani 等将状态、拓扑与停电变量放在同一个混合整数二次规划中联合估计，并在实际配电馈线上验证；其证明重点是同时检测拓扑错误与停电，而不是只报告状态估计精度。Li、Pandey 与 Pileggi 的 ckt-GSE 使用加权最小绝对值与稀疏 slack 变量，通过假设检验检测、辨识并拒绝错误开关状态，并专门讨论 node-breaker 模型上拓扑错误的不可检测性。Ghosal 通过可观测／不可观测子空间分解，区分传感器坏数据与建模／拓扑错误。WLAV 拓扑错误检测则提供了残差检验与假设检验的经典路线。

这些工作的共同证明协议是：

1. 构造已知的拓扑错误，保留真实拓扑与真实状态作为 ground truth；
2. 把拓扑作为待估变量，或对假定拓扑做残差／假设检验；
3. 将检测与辨识分开报告，并报告误报；
4. 讨论不可检测边界，把物理上不可观测的错误单独处理。

对本文的启示是：S1 应把“检测拓扑不一致”与“定位故障候选”分开；应报告误报率；应把物理上不可检测的拓扑错误单独分层，不能算作模型失败。

### 3.3 拓扑变化下的故障定位

Chen 等在 IEEE 123 节点系统上生成 13,520 个样本、119 个故障母线类别，故障电阻 0.05 至 20 欧姆，测试量测噪声、数据丢失、网络重构与高阻故障，并使用数据增强与多种基线比较。Karabulut 等系统比较多种循环图神经网络在不同拓扑设置下的泛化，报告 RGATv2 的 F1 下降约 12%，纯循环网络最多下降约 60%，其他图网络最多下降约 25%。

这些工作测试的是物理拓扑变化，并且输入给模型的拓扑是正确更新后的拓扑。它们对应本文的 S3，而不是 S1。它们没有回答：物理拓扑未变、模型拿到错误台账时，模型会不会把这种不一致误判为某个故障候选。该区别是本文 S1 的主要空白。

### 3.4 开放集、选择性与拒识

Gao 等针对开放集故障诊断，使用极值理论建模未知信息，从而拒绝未知故障；HIRA-DGA 在跨数据源变压器诊断中显式输出 HOLD，表示标签结构不受支持，并使用外部数据验证、Wilson 置信区间与消融；Geifman 与 El-Yaniv 的选择性分类通过风险—覆盖率曲线，在给定目标风险下拒绝样本；Angelopoulos 与 Bates 的保形预测提供无分布假设的覆盖保证，并可在预测集合过大或为空时弃权。

这些工作的共同证明协议是：

1. 明确“已知／未知”或“可接受／应拒识”的划分；
2. 在独立验证集上校准阈值或覆盖参数，测试集不参与校准；
3. 报告接受样本上的风险、覆盖率、拒识率、检测 AUROC 或覆盖率保证；
4. 与不拒识、最大 softmax、能量分数、集成方差等基线比较；
5. 报告外部验证与置信区间。

对本文的启示是：拒识不是“softmax 低”的同义词，而是一个带目标风险的决策层；S1 应报告风险—覆盖率，而不是只报告 Top-1。

### 3.5 小结

S1 的证明应分成四层：检测（是否存在拓扑不一致）、辨识（哪条边或开关错）、定位（故障候选）、拒识（是否应弃权）。当前 S1 只做了定位一层，而且没有区分物理不可检测与模型误判。本文的方案在不新增模型模块的前提下，补齐检测、误归因与拒识三层。

## 4. 验证方案：选择性可靠

### 4.1 可部署的一致性分数

GReF 的 `candidate_score` 由 `response_energy` 给出，本质是掩码响应距离 $d_S$。对事件 $m$ 与候选 $k$ 记 $d_{m,k}$，取最小与次小 $d_1$、$d_2$，定义归一化候选间隔：

$$
r_m=\frac{d_2-d_1}{d_2+d_1+\epsilon}\in[0,1].
$$

该分数只使用模型输出，不使用真实标签，因此部署可用。计算 $d_1$、$d_2$ 时只使用故障母线候选；正常候选不并入定位排序，单独用于检测或拒识。需要区分：现有 `rank_metrics` 中的 signed margin 使用真实候选与最难错误候选，属于评价指标，不能作为部署置信度；$r_m$ 使用最优与次优候选，才是可部署的。

判定规则为二维：

- 当 $d_1\le\tau_d$ 且 $r_m\ge\tau_r$ 时，接受最优候选；
- 否则拒识，并输出“拓扑一致性不足，建议核查拓扑或补充量测”。

使用两个判据的原因是：$d_1$ 只能发现“所有候选都拟合很差”，$r_m$ 只能发现“最优与次优难以区分”；单独使用任何一个都会漏掉另一类失败。

### 4.2 阈值校准

阈值只在干净验证集上校准，测试集不参与。校准目标可以设为干净事件的联合拒识率不超过 5%，或设为在干净验证集上达到预设的选择性风险。若验证集族数允许，采用分组交叉拟合，避免阈值对验证集过拟合；若族数不足，至少报告阈值的不确定性。在 96 条事件、6 个故障族的规模下，阈值估计的不确定性较大，应报告 bootstrap 区间，不以 5% 作为精确值。

校准时应按故障阻抗、负荷水平或事件难度分层，避免把“高阻故障本身残差大”误判为“拓扑不一致”。分层阈值或分层校准是允许的，不构成新模型模块。

### 4.3 三种结果

对每个事件，模型输出三类结果之一：

- 正确接受：接受且最优候选等于真实故障位置；
- 错误接受：接受但最优候选不等于真实故障位置，即误归因；
- 拒识：不接受任何候选，提示拓扑核查或补充量测。

在干净事件上，拒识是误报；在损坏事件上，拒识可能是正确行为，但也会拒掉本来可以正确接受的样本。风险—覆盖率曲线用于刻画这一取舍。

### 4.4 实验矩阵

实验采用同一事件、同一观测、同一 $G^{true}$，只改变 $G^{obs}$ 的配对设计：

- 模型：冻结的当前 GReF，不重新训练；
- 事件：现有测试集的故障事件，按故障族分组；
- 损坏：删边 1、2、3 条，区分故障附近与随机位置；每条事件采样多个损坏图，例如每个严重度 20 个；
- 对照：安慰剂边，即与故障电流路径无关、或对候选响应影响极小的边；
- 种子：损坏采样使用 5 个随机种子；训练种子保持不变；
- 统计：按故障族做配对 bootstrap，报告置信区间。

正式 S1-EN 协议只使用正常 S0 数据训练，边删除仅在推理阶段施加；训练期边删除增强不属于正式协议，若执行只能作为单独标注的消融，不得与主结果混合。

配对设计的作用是控制事件难度：同一事件在干净与损坏条件下的差异，比不同事件之间的聚合差异更接近因果效应，也能提高小测试集下的统计功效。

### 4.5 指标

- 检测：以 $r_m$ 或 $d_1$ 为分数，计算干净与损坏事件的 AUROC 与 AUPRC；报告固定干净拒识率下的损坏检出率。
- 误归因：损坏事件中被接受且定位错误的比例；以及其中高置信误归因的比例。
- 定位：在接受样本上计算 Top-1／Top-3／Top-5，并同时报告覆盖率。
- 选择性风险：接受样本上的错误率；按覆盖率扫描，形成风险—覆盖率曲线。
- 校准：期望校准误差或可靠性图；至少报告接受阈值附近的校准情况。
- Oracle 相对指标：使用真实响应与 `oracle_rank_metrics` 的真实候选间隔，分层物理可分与物理模糊事件；报告模型间隔相对 Oracle 间隔的保留率。
- 基线：无条件 argmax；最小候选分数阈值；对负能量做 softmax 后的最大概率阈值；若模型已有不确定度分支，再加入集成方差或 MC dropout。

### 4.6 分层

所有主指标按以下维度分层报告：

- 错误类型与严重度；
- 错误位置：故障附近、故障下游、远端、无关分支；
- 故障阻抗与负荷水平；
- Oracle 候选间隔：物理可分与物理模糊；
- 相关边与安慰剂边。

分层的目的不是增加结论数量，而是回答“拒识是否真的对拓扑错误敏感”，而不是对故障难度敏感。

### 4.7 控制

第一，高阻对照。按故障阻抗分箱，比较同一阻抗箱内干净与损坏事件的拒识率。只有在每个阻抗箱内损坏事件拒识率都更高，才能说拒识对拓扑错误有特异性。

第二，安慰剂边。对每个事件额外删除一条与故障电流路径无关的边。如果相关边与安慰剂边的拒识率相同，说明一致性分数只是在检测“图变了”，而不是“物理解释不一致”。

第三，Oracle 分层。用真实响应的候选间隔区分物理可分与物理模糊事件。在物理模糊层，拒识是合理行为；在物理可分但模型仍误归因的事件上，才是模型失败。

第四，配对统计。以同一事件的干净／损坏配对差为分析单位，按故障族做 bootstrap，不把 96 条事件当作独立样本。

### 4.8 最小实现边界

本方案不修改模型、损失或训练流程。需要新增的代码限于评估与决策层：

- 一个评估脚本，负责加载 GReF 与现有数据、生成删边与安慰剂边、前向计算 `candidate_score`、计算 $d_1$、$d_2$、$r_m$、三类结果与风险—覆盖率，并输出 JSON／CSV 与图件；
- 一个小型工具模块，提供归一化间隔、阈值校准、结果表与风险—覆盖率函数。

可直接复用的现有接口包括 `load_dataset`、`response_energy`、`edge_mask`、`oracle_rank_metrics` 与现有分组划分。GReF 的 `candidate_score` 已经是响应能量，不需要新增评分头。

### 5.2 判定

本方案采用预先登记的判定条件：

- 检测：$r_m$ 或 $d_1$ 对干净／损坏事件的 AUROC 高于随机分数与负能量 softmax 基线，或固定干净拒识率下的损坏检出率高于这些基线；
- 误归因：在目标干净拒识率下，损坏事件的高置信误归因率显著低于无条件 argmax 基线；
- 拒识：在目标选择性风险下，损坏条件的覆盖率不低于预先登记的下限，且与干净条件可比；
- 特异性：相关边的拒识率高于安慰剂边，且高阻分层后结论不反转。

若上述条件成立，可以支持“选择性可靠”的有限主张；若不成立，则应报告负面结果，即当前模型的候选间隔不足以指示拓扑不一致，需要显式的拓扑一致性模块或拓扑错误增强训练。负面结果同样是有效结论，不应通过增加模块来掩盖。

## 6. 可支持的结论与边界

在条件成立时，本文可以支持如下有限结论：

> 在 IEEE13、单相接地、合成且无独立量测噪声的数据、冻结 GReF、边缺失型拓扑台账错误下，模型在可检测错误上要么正确定位，要么拒识或提示核查；其高置信误归因率显著低于无条件 argmax 基线，且在干净事件上的拒识率受预设目标控制。

该结论不能外推到：边虚增、连接错接、开关状态反转、相别错误、母线合并或拆分、候选轴变化；物理断线或真实拓扑变化；跨拓扑泛化；真实量测噪声；多故障；S4 高阻域；其他算例或训练种子。上述外推需要另行登记数据契约与实验。

## 7. 阶段计划

第一阶段，复算与准备。在 GReF 上重跑 S1-EN 推理，计算 $d_1$、$d_2$、$r_m$ 的分布，核对现有 candidate-score 结果与 GReF 结果的差异；确认测试集、分组划分与边掩码接口；完成阈值校准与评估脚本的单元测试。

第二阶段，主实验。完成删边 1／2／3 条、局部／随机、安慰剂边、5 个损坏种子的配对实验；产出图 1 至图 3 与指标表；执行第 5.2 节的判定。

第三阶段，扩展。在边全集可构造的前提下，加入边虚增、开关状态反转、连接错接与相别错误；必要时加入拓扑错误增强训练，但该训练属于方法改动，须另立计划，不与本方案的“不新增模块”主张混写。

第四阶段，组合场景。与 S2 部分观测、S4 高阻组合，检验拒识层在复合退化下是否仍然有效；该阶段需要重新登记数据与配置。

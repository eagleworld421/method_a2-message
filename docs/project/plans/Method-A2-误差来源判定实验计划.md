# Method-A2 误差来源判定实验计划（重新制定版）

## 1. 本文与原计划的关系

本文取代《Method-A2-反事实响应预测误差来源分析》的实验设计部分，只保留其“不设计新模型结构、不加入新损失、不做针对性调参、保持实验之间公平比较”的执行约束。原计划的目标表述（分析误差来源、为是否引入共享状态表示提供依据）本身没有问题，但其三组实验的构造无法达成该目标，这一点已在《Method-A2-误差来源公式核验与实验证据审计》与《Method-A2-误差来源三组信息条件实验报告》中给出实测证据。

本文重新定位任务如下。

> 给定 $X_m=\psi(G_m^{true},H_m,C_m,K_m^{true})$ 与监督目标 $\{S^{CF}_{m,k}\}_{k\in\mathcal K_m}$，判定当前模型误差 $\widehat S(X_m)$ 相对 $S^{CF}_{m,k}$ 的主要来源，是**从 $X_m$ 提取 $(H_m,C_m)$ 失败**，还是**由 $(H_m,C_m,k)$ 生成 $S^{CF}_{m,k}$ 的映射失败**。

本文只定义实验与判定规则，不设计 $U$、不设计 encoder/decoder 结构、不设计损失函数，也不执行任何实验。

## 2. 原计划不可判别的四处原因

以下四点是重新设计的直接依据，均已由既有产物证实。

第一，三组实验共享同一条候选条件化解码路径。若误差就产生在这条路径上，三组臂会同时变差，任何输入信息都改变不了读数，实验必然给出“平”的结果，而“平”在原计划的判定逻辑中既不能证明也不能排除任何来源。判定误差来源的前提是：不同的候选解释必须做出**不同**的预测。

第二，原计划的 Experiment 2 与 Experiment 3 输入定义相同，均为 $(H_m,C_m,k)$，二者差别只在“条件是否逐候选进入解码”，而该差别并非原计划声明的自变量，因此其声称隔离的 $k$ 变化效应并未被隔离。

第三，“状态”被具体化为 $(H_m,C_m)$ 的 22 维标量向量，但该向量不含故障前工作点（潮流解），而响应族对该工作点敏感；实测 Experiment 2 的族级误差均值 $8.291738\times10^{-3}$ 高于基线 $7.674937\times10^{-3}$，中位数 $2.027216\times10^{-3}$ 是基线 $1.145166\times10^{-3}$ 的 $1.77$ 倍。该结果不能读作“状态无用”，只能读作“这组标量没有携带基线已从观测中获得的信息”。

第四，原计划继承误差加法分解 $E_{total}=E_{state}+E_{candidate}$，而该式在平方量口径下不是恒等式，且 $E_{state}$ 依赖一个未指定的提取算子。本计划改用**协议差值**定义归因量，不使用加法分解。

## 3. 问题归约与两个判据

### 3.1 关键的数据生成事实

数据集的构造方式决定了以下事实，它们是判据设计的基础。

- 每个事件会对全部 $N$ 个母线候选与一个正常候选各求解一次，得到签名库 $[K,N,T,F]$，因此 $\{S^{CF}_{m,k}\}_{k\in\mathcal K_m}$ 在同一个 $(H_m,C_m)$ 下共享其余全部条件，只改变故障位置。
- 事实响应是签名库中真实位置的那一片：$X_m=\mathrm{bank}_m[K_m^{true}]$。因此 $X_m$ 与 $S^{CF}_{m,k}$ 位于**同一响应空间**，且 $K_m^{true}$ 必然可从 $X_m$ 恢复（它正是 $X_m$ 自身）。
- 每个 block 含 4 个事件，同 block 内 `load_multipliers` 相同而 `fault_class` 与 `true_impedance` 不同，`true_location` 互不相同。因此数据集不存在“同一 $(H_m,C_m)$ 下只改变真实位置”的事件对，$(H_m,C_m)$ 的可辨识范围只能通过 400 个 block 与 5 类故障条件来界定。

由第二点得到一条对判定至关重要的推论：**从 $X_m$ 提取 $(H_m,C_m)$ 时，$K_m^{true}$ 是被“免费”给出的**，因为 $X_m$ 就是真实位置下的响应。所以“提取失败”不可能表现为“找不出真实位置”，而只能表现为“在已知真实位置的前提下仍然算不准共享状态”。这与既有实测一致：真实候选的定位失败不是因为 $X_m$ 不含位置信息，而是因为模型预测的候选族与 $X_m$ 的相对关系被破坏。

### 3.2 判据一：提取判据

判据一检验：**模型是否真的把 $(H_m,C_m)$ 的知识装进了它中间传递的表示。**

该判据不依赖任何关于 $U$ 的形式假设，只用两个可测事实：

- 冻结当前模型编码器，用它的中间表示去预测 $H_m$ 与 $C_m$。若这些量能从表示中以很小的误差恢复，说明知识已经在表示里；若恢复误差很大，说明表示没有承载这些量。
- 同一 block 内的 4 个事件共享 $(H_m,C_m)$，因此表示若真的编码 $(H_m,C_m)$，应表现出可测的 block 内一致性（相对 block 间差异）。该比值是 $K_m^{true}$ 污染程度的直接度量。

判据一的作用是**排除**：若表示为下游已经提供了足够的 $(H_m,C_m)$ 信息，则“提取不足”不能被列为误差来源，无论端到端误差多大。

### 3.3 判据二：映射判据

判据二检验：**在 $(H_m,C_m)$ 完全已知的条件下，$(H_m,C_m,k)\to S^{CF}_{m,k}$ 这个映射在当前参数化与数据规模下是否可学。**

该判据必须独立于提取，因此它的输入侧不使用 $X_m$，并且必须先通过小样本过拟合检查，以区分“映射不可学”与“优化或容量不足”。

判据二的作用同样是**排除**：若连条件完全已知且能过拟合小样本的解码器都学不好该映射，则任何共享状态表示都无法改善候选生成，因为改进输入表示不能降低映射本身的难度。

## 4. 误差量的定义

本文不使用加法分解，改用协议差值定义归因量，并且所有误差统一使用正式 $d_S$（节点—特征权重 $1/(s_{n,f}^2+10^{-8})$，分母为掩码元素数 $N\cdot T\cdot F$，平方量口径）。凡涉及开方口径的比较必须单独声明。

记基线协议为 $P_1$：以 $X_m$ 为输入、输出整族候选响应。记 oracle 状态为 $U^*_m$，其内容在第 6 节定义。

- $E_1$：$P_1$ 在测试集上的族级 $d_S$ 及其逐事件、逐候选分布。
- $E_3$：以冻结的基线表示为输入、在训练期可见 $(H_m,C_m,k)$ 的解码器的族级误差。
- $E_4$：以 $X_m$ 侧的真实状态注入后的可训练模型的族级误差。
- $E_5$：完全以 $U^*_m$ 与候选为输入的映射的族级误差。
- $E_6$：仅以候选身份为输入的下界协议误差。
- 常数族基线 $E_{const}$：以训练集候选响应均值为预测族。

由此定义两个归因量。

- 提取归因量：$D_{state}=E_4-E_3$。其含义是“把真实的 $(H_m,C_m,k)$ 交给同一个冻结表示时误差能降到多少”。$D_{state}$ 大表示冻结表示没有提供所需信息，即提取是瓶颈；$D_{state}$ 小表示表示已经够用，提取不是瓶颈。
- 映射归因量：$D_{map}=E_5-E_{const}$。其含义是“条件完全已知时，映射是否还能显著优于什么都不做的常数族”。$D_{map}$ 小表示条件已知也无法改善，即映射本身是瓶颈。

两个归因量分别对应两个判据，且**互不依赖**：$D_{state}$ 在基线表示上测量，$D_{map}$ 在 oracle 输入上测量。

同时定义三个必须与误差一起报告的判别类指标，它们衡量误差是否落在候选判别上而非族级水平上。

- 候选方向能量比：预测族去掉候选均值后的能量与真值同量之比的中位数。
- 剖面相关：逐事件候选间距离剖面（$k$ 两两距离）的相关系数中位数。
- 候选散布比：预测族在候选轴上的散布与真值族在候选轴上的散布之比中位数，同时报中位数、$p95$ 与去尾 $5\%$ 后的值，避免被离群事件主导。

## 5. 实验阶段总览

实验按阶段依赖组织，前阶段的判定决定后阶段是否执行，避免一次性投入全部算力。

```text
E0 基线与判别指标复算
    ↓
E1 判据一：冻结表示的状态内容检验（免训练 probe + block 内一致性）
    ↓
E2 判据二的可行性前置：oracle 条件映射的小样本过拟合检查
    ↓
若 E2 未通过 → 判定为映射不可学，停止，不进入 E3–E5
    ↓
E3 判据一主实验：冻结表示 + oracle 条件解码
    ↓
E4 判据二主实验：可训练的全 oracle 条件映射
    ↓
E5 归因细粒度：位置 / 故障条件 / 工作点三者的贡献分解
    ↓
E6 输出侧条件敏感性检验
```

## 6. oracle 状态 $U^*_m$ 的定义

$U^*_m$ 只包含**生成该事件响应族所必需、且在真实部署中不可见**的量。分三类，分类是为了 E5 的归因。

- $U^*_{pos}=K_m^{true}$：真实故障母线。由 3.1 可知该量可被 $X_m$ 免费给出，因此它在 E5 中用作对照，用于检验“收益是否只是位置泄漏”。
- $U^*_{cond}=C_m$：故障类型（单热，5 类）、`log1p(true_impedance)`、`fault_delay_steps`，共 7 维。全部来自事件元数据，事实可用。
- $U^*_{op}=H_m$ 的工作点部分：15 个负荷乘子与**故障前稳态电压**（各节点三相幅值与相角）。负荷乘子来自事件元数据；故障前电压在数据集的响应构造中已经参与生成（签名由故障前电压与故障后电压共同构造），因此在实现阶段必须先从响应数组与生成代码中确认其可恢复性，并在 E0 中记录确认结果。

若 $U^*_{op}$ 的故障前电压无法从既有数组恢复，则退化为只用负荷乘子，并在报告中明确标注该退化，同时把“工作点不可用”列为结论的边界条件。

## 7. 逐实验定义

### E0 基线与判别指标复算

- 目的：固定 $E_1$、$E_{const}$ 与三个判别类指标，作为后续所有比较的参照；同时确认 oracle 状态字段的实际可用性。
- 输入：既有 `paired-v1-ieee13-1600-seed342`、既有 `pi-response-full-20260920-1600-seed342-v2` 的 student 变体 checkpoint。
- 步骤：复算测试集 240 事件的族级 $d_S$（均值、中位数、$p90$、$p95$）、逐候选 $d_S$、逐事件 $d_S$、常数族基线，以及三个判别类指标；同时逐字段核验 $U^*_{cond}$、$U^*_{op}$ 是否可由既有数组与元数据恢复，并输出核验记录。
- 可证伪预测：$E_1$ 应与既有记录一致（族级均值 $7.674937\times10^{-3}$、中位数 $1.155938\times10^{-3}$）。若不一致，先停查数据与距离实现，不进入后续阶段。
- 阶段门：oracle 状态字段核验通过才允许进入 E2。

### E1 判据一：冻结表示的状态内容检验

- 目的：回答“模型是否把 $(H_m,C_m)$ 装进了表示”，为后续“提取是否不足”提供独立于端到端误差的证据。
- 输入：冻结编码器在事件 $m$ 上的中间表示（候选条件编码器的节点级与全局表示，按实现取用）。
- 步骤：在冻结表示上拟合只含线性层的 probe，标签为 $U^*_{cond}$、$U^*_{op}$ 与 $U^*_{pos}$，报告测试集上的回归 $R^2$ 与分类准确率；同时按 block 计算表示的 block 内离散度与 block 间离散度之比。
- 可证伪预测：若表示确实承载 $(H_m,C_m)$，则 probe 的 $R^2$ 应显著高于“用常数预测”的基线，且 block 内离散度应明显小于 block 间离散度；若 probe 的 $R^2$ 接近 $0$ 而 block 内离散度接近或超过 block 间离散度，则表示为下游提供的信息不足。
- 预先登记的判定规则：以“probe $R^2$”与“block 内/block 间离散度比”两个量共同判定。任一量显示信息充足即记为“表示信息充足”；两者同时显示信息不足才记为“表示信息不足”。该判定只在 E3 得出结论后用于互证，不单独作为最终结论。

### E2 判据二的可行性前置

- 目的：在投入完整训练之前，确认 $(H_m,C_m,k)\to S^{CF}_{m,k}$ 在当前参数化下是否至少能被拟合，从而区分“映射不可学”与“优化或容量不足”。
- 输入：$U^*_m$ 与候选身份 $k$，不使用 $X_m$。
- 步骤：固定随机种子，随机选 32 个事件，用与后续 E4 完全相同的模块与优化器配置训练，使其在训练样本上的族级 $d_S$ 收敛到接近零；报告初始与最终训练误差及其比值。
- 预先登记的判定规则：若最终训练误差与初始之比不大于 $0.1$（与既有可辨识性实验中 I2 的过拟合检查口径一致），记为通过；否则判定为“映射在本参数化下不可学或优化不成立”，停止后续阶段，结论写成“候选生成映射不可学”，而不是“状态提取错误”。
- 允许的处置：若未通过，可先检查优化与容量（提高学习率、增大隐藏宽度、延长轮次）作为诊断，但该检查必须作为独立条目记录，不得与主判定混写。

### E3 判据一主实验：冻结表示 + oracle 条件解码

- 目的：在基线表示被冻结、不会被训练改变的前提下，测量“把真实 $(H_m,C_m,k)$ 注入同一条解码路径能把误差降到多少”，得到 $E_3$ 与 $D_{state}=E_4-E_3$ 中的被减项。
- 输入：基线编码器的中间表示（冻结，不接收梯度）与 $(H_m,C_m,k)$。
- 步骤：冻结基线编码器与候选条件编码器；只训练解码头，输入为“冻结表示 + 真实条件 + 候选描述”；用与 E0 相同的划分、种子与评价口径报告 $E_3$。
- 可证伪预测：若提取是瓶颈，则 $E_3$ 应显著低于 $E_1$；若 $E_3$ 与 $E_1$ 同量级，则冻结表示已经足以支撑下游，提取不是瓶颈。
- 预先登记的判定规则：以相对差 $(E_1-E_3)/E_1$ 判定。该相对差不大于 $0.10$ 记为“冻结表示充足”；不小于 $0.30$ 记为“冻结表示不足”；介于两者之间记为“证据不足”，需结合 E4 与 E5 判断。判定同时要求逐事件配对差的中位数方向一致，避免由少数事件驱动。

### E4 判据二主实验：可训练的全 oracle 条件映射

- 目的：在不冻结任何部分、且条件完全已知的条件下，测量映射自身能达到的水平，得到 $E_5$ 与 $D_{map}$。
- 输入：$U^*_m$ 与候选身份 $k$，不使用 $X_m$。
- 步骤：用与 E0 相同的划分、种子与训练配置训练条件映射，报告 $E_5$ 与三个判别类指标；同时报告与常数族 $E_{const}$ 的比值。
- 可证伪预测：若映射可学，$E_5$ 应显著低于 $E_{const}$ 且判别类指标应接近真值；若 $E_5$ 与 $E_{const}$ 同量级，则条件完全已知也无法改善预测，映射本身是瓶颈。
- 预先登记的判定规则：以 $D_{map}=E_5/E_{const}$ 判定。比值不大于 $0.5$ 记为“映射可学”；不小于 $0.9$ 记为“映射不可学”；介于两者之间记为“映射仅部分可学”。
- 与 E3 的互证要求：若 E3 得到“冻结表示充足”而 E4 得到“映射可学”，则两者不能同时成立而不矛盾，此时必须检查 E3 的解码头是否在“表示 + 真实条件”的输入上过度拟合或被条件主导，检查结论记入报告。

### E5 归因细粒度分解

- 目的：判定状态注入的收益属于位置、故障条件还是工作点，从而把“提取不足”细化到具体缺失量。
- 输入：$U^*_{pos}$、$U^*_{cond}$、$U^*_{op}$ 的不同组合与候选身份 $k$。
- 步骤：固定 E4 的模块与配置，只改变输入条件组合，分别训练并报告：仅位置、仅故障条件、仅工作点、故障条件加位置、工作点加位置、全部三类。每一组报告 $E$ 与三个判别类指标。
- 可证伪预测：若收益主要来自 $U^*_{pos}$，说明“误差来自未能确定真实位置”，而由 3.1 可知位置本可免费获得，因此该结果指向的是模型没有利用已有信息，而不是信息缺失；若收益主要来自 $U^*_{op}$，说明误差来自未能恢复运行工作点；若三类都不带来收益，则与 E4 的“映射不可学”一致。
- 预先登记的判定规则：以“加入某一类后相对仅候选条件的误差下降比例”排序，下降比例最大者即归因对象；若最大下降比例小于 $0.10$，记为“三类条件均无显著贡献”。

### E6 输出侧条件敏感性检验

- 目的：从输出侧独立检验候选条件是否真的进入了预测，用于交叉验证 E3–E5 的结论。
- 输入：E0 基线模型的输出。
- 步骤：对每个事件计算预测族在候选轴上的散布，与真值族在候选轴上的散布比较；计算候选方向能量比与剖面相关；另外对 E4 的模型做条件置换，报告响应改变量。
- 可证伪预测：若候选条件已进入预测，预测族应随候选变化且散布比接近 $1$；若散布比远小于 $1$，说明模型几乎没有利用候选轴信息。
- 预先登记的判定规则：散布比中位数不大于 $0.5$ 记为“候选轴信息利用不足”，且该结论必须与 E3/E4 的结论分开陈述，因为它不区分提取与映射。

## 8. 判定规则汇总

最终判定由 $D_{state}$ 与 $D_{map}$ 两个归因量决定，四个格子对应四种结论。

- $D_{state}$ 大且 $D_{map}$ 小：**提取失败**。冻结表示没有把 $(H_m,C_m)$ 传给下游，而条件已知时映射可用。下一步研究对象是“如何把观测中的共享状态组织成可传给解码器的表示”，此时讨论 $U$ 才具备证据基础。
- $D_{state}$ 小且 $D_{map}$ 大：**映射失败**。表示已经够用而映射本身学不好，改进表示不会改善结果。下一步研究对象是“$(U,k)\to S$ 的映射参数化与训练目标”，而不是 $U$ 的设计。
- 两者都大：**联合失败**。提取与映射都需改进，且必须注意 E3 与 E4 的互证要求可能失效，需要先排除测量偏差。
- 两者都小：**既非提取也非映射**，误差落在别处（候选掩码与评价口径、数据划分内的条件覆盖、离群事件主导均值等）。此时应优先复核 E0 的判别类指标与离群事件构成，而不是提出新结构。

判定必须同时满足下列附加条件，否则结论降级为“证据不足”。

- 三个判别类指标必须与误差结论方向一致。若误差下降而判别类指标不改善，则该下降不能作为“候选生成改善”的证据。
- 所有改善声明必须给出逐事件配对差的分布，而不是只给均值。
- 若结论依赖的差值在去掉最差 $5\%$ 事件后反转，结论降级。

## 10. 算力预算

按既有记录的同类实验耗时估计，单臂训练约 4 分钟（100 轮、1120 训练事件、batch 16、GPU）。全部阶段的估算如下。

- E0：无训练，约 $1$ 分钟；E1：probe 训练约 $2$ 分钟；E2：32 样本过拟合约 $1$ 分钟；E3：约 $4$ 分钟；E4：约 $4$ 分钟；E5：6 臂约 $24$ 分钟；E6：无训练，约 $1$ 分钟。

## 12. 本计划不能证明什么

- 不能证明表示结构 $U$ 有效或无效。本计划注入的是**信息**（真实条件），不是表示结构；注入点选择在解码器输入侧，因此结论只能回答“该信息是否存在、是否已被传递、映射是否能用它”，不能回答“$U$ 应该长什么样”。
- 不能外推到 S1 错误拓扑、S2 部分观测、S3 跨拓扑、S4 高阻域与真实传感器噪声；本计划全部在 S0 单拓扑、全节点观测、单一数据划分下完成。
- 不能在有限数据上证明 $X\to\mathcal S^{CF}$ 的严格唯一性，只能给出经验对应关系与其误差结构。
- 不能把“条件已知时映射可学”等同于“部署时可达”，也不能把“条件已知时映射不可学”等同于“任务不可解”，后者只说明当前参数化与数据规模下不可学。

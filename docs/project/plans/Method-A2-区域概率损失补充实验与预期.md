# Method-A2 RaReF 区域概率损失补充实验与预期

## 1. 已有结果与后续问题

RaReF 区域概率损失第一阶段以

\[
L=1.0L_E+0.3L_R+0.1L_{\mathrm{region}}
\]

替换图平滑损失。第二阶段进一步根据梯度投影扫描能量权重和排序／区域混合比例，选定：

\[
\lambda=(\lambda_E,\lambda_R,\lambda_{\mathrm{region}})
=(1.0,0.141,0.194).
\]

该配置在单种子验证和一次测试评价中表现为：

- 完整观测 Top-1 为 92.54%；
- 真实故障节点被观测时的部分观测 Top-1 为 87.68%–94.78%；
- 真实故障节点未被观测时的区域覆盖率为 94.13%–97.78%；
- 未观测子集单节点 Top-1 为 27.17%–70.00%；
- 平均区域大小约为 7.15–8.19 个节点。

但重复点显示覆盖率约有 2.8 个百分点的运行波动，因此当前配置相对第一阶段的覆盖率优势尚不能视为稳定效应。与此同时，第二阶段配置改善了观测条件下的单点定位，却使未观测子集单节点 Top-1 低于第一阶段。

后续实验需要分别确认两件事：

1. 该配置是否稳定地提供高覆盖率和较小区域；
2. 在不牺牲覆盖率的前提下，能否恢复未观测故障节点的单点定位能力。

## 2. 已完成事项与不再执行的事项

第二阶段已经完成能量权重与排序／区域混合比例扫描。后续不再扩大 \(\lambda_E\) 范围，也不再继续细分同一权重网格。

原因是：

- \(\lambda_E=10\) 的部分配置已出现完整观测性能约束失败；
- 排序和区域梯度方向高度正相关，继续沿同一网格移动不能充分分离机制；
- 第二阶段重复点的覆盖率波动大于选定配置相对第一阶段的覆盖率差异。

后续权重工作只保留多种子复核，不再把单种子验证覆盖率作为继续调权的依据。

## 3. 后续实验一：多种子配对复核

### 3.1 目的

确认区域损失的收益是否超过单种子和单次运行波动，并区分“区域定位配置”和“单点恢复配置”。

### 3.2 配置

至少使用 3 个预先指定的随机种子，比较：

- 原始 A tau1x：\((1.0,0.3,0.1)\)；
- 第一阶段区域配置：\((1.0,0.3,0.1)\)；
- 第二阶段选定配置：\((1.0,0.141,0.194)\)。

如资源允许，可加入 e3-m30 配置 \((3.0,0.141,0.194)\) 作为能量权重对照，但不使用它重新扩展网格。

所有配置使用相同数据划分规则、相同掩码生成规则和相同评价脚本。比较应按相同种子和相同掩码逐事件配对。

### 3.3 主要指标

- 完整观测 Top-1；
- 真实节点被观测子集 Top-1；
- 真实节点未被观测子集 Top-1；
- α=0.1 区域覆盖率；
- 平均区域大小、P90 区域大小；
- 区域拓扑半径和中心距离；
- 各指标的种子间均值、标准差和逐掩码差值。

### 3.4 预期

若第二阶段配置的覆盖率和区域大小优势在多个种子上保持，才能把它定为区域定位配置。若其未观测子集 Top-1 始终低于第一阶段，则应明确把它解释为“高覆盖区域定位”方案，不再宣称单点定位全面提升。

## 4. 后续实验二：未观测条件下的定向参数实验

### 4.1 目的

在保持第二阶段选定权重的前提下，尝试恢复未观测故障节点的单点 Top-1，同时维持区域覆盖率。

### 4.2 参数范围

固定：

\[
\lambda=(1.0,0.141,0.194),
\qquad
\beta_{\mathrm{obs}}=0.05,
\]

只扫描：

\[
\beta_{\mathrm{miss}}\in\{0.2,0.3,0.4\},
\qquad
\sigma\in\{0.5,1.0\}.
\]

其中 \(\sigma=1.0\) 是当前基线，\(\sigma=0.5\) 用于检验更集中的邻域目标能否提升未观测单点定位。暂不使用 \(\sigma=1.5\)，因为当前区域已经达到约 7–8 个节点，进一步扩大核可能只增加区域而不能缩小范围。

### 4.3 选模约束

验证集配置必须同时满足：

- 未观测故障子集 α=0.1 覆盖率不低于 0.95；
- 平均区域大小不明显超过第二阶段配置；
- 真实节点被观测子集 Top-1 不出现系统性下降。

在满足约束的配置中，优先选择未观测子集单节点 Top-1 更高者。若降低 \(\beta_{\mathrm{miss}}\) 或 \(\sigma\) 后 Top-1 提升但覆盖率下降，则记录为单点—区域不可避免的权衡，不将其判为全面改进。

### 4.4 预期

- 降低 \(\beta_{\mathrm{miss}}\) 预计会收紧未观测条件下的概率分布，提高 Top-1，但可能降低区域覆盖率；
- 降低 \(\sigma\) 预计会缩小区域半径，但对远距离候选的容错下降；
- 如果两者均不能在覆盖率约束下提升 Top-1，说明当前响应信息不足以稳定恢复未观测故障单点，后续应停止继续调节区域目标。

## 5. 后续实验三：置信度与区域覆盖率校准

### 5.1 目的

验证单节点概率和区域概率是否具有可部署的经验覆盖含义，并避免仅凭 softmax 数值解释置信度。

### 5.2 方法

- 只使用验证集标定单节点概率温度；
- 由校准后的单节点概率重新计算区域概率；
- 对 \(\alpha\in\{0.05,0.1,0.2\}\) 生成最小概率区域；
- 按完整观测、故障节点被观测和故障节点未被观测分别报告覆盖率；
- 绘制覆盖率—区域大小曲线，并报告最差掩码组。

### 5.3 预期

温度校准预计主要改善概率数值和覆盖率的对应关系，不一定改变候选排序。如果覆盖率明显高于目标而区域过宽，应优先使用校准后的最小区域，而不是继续提高区域损失权重。

## 6. 结果判定

### 6.1 区域定位配置成立

同时满足以下条件时，可将配置称为区域定位配置：

- 多种子下未观测故障区域覆盖率稳定高于原GRReF 模型；
- 在相近覆盖率下平均区域大小或拓扑半径更小；
- 完整观测和真实节点被观测子集 Top-1 没有系统性退化；
- 区域覆盖率优势超过重复运行波动。

### 6.2 单点恢复配置成立

只有在满足区域覆盖率约束的同时，未观测故障子集单节点 Top-1 也在多种子下稳定提高，才能称为单点恢复配置。否则只能报告为高覆盖率区域定位。

若只能提高覆盖率而区域接近全图，或只能提高 Top-1 而覆盖率明显下降，则分别记录为概率扩散或单点偏置，不能判定为全面优化。

## 7. 产物、停止条件与解释边界

每个阶段至少生成配置清单、逐配置验证指标、逐掩码条件分解、覆盖率—区域大小曲线、种子间汇总和运行报告。任一配置出现非有限损失、区域目标不归一、候选轴不能对齐、掩码条件标签错误或测试集被用于选参时，停止该配置并记录原因。

本计划只支持在当前 IEEE37 S0 数据、当前候选拓扑、当前故障类型与部分节点观测定义下比较RaReF 区域概率损失，不能直接外推到 S1 拓扑错误、传感器噪声、非随机缺测、跨拓扑算例或连续工况变化。

## 8. 执行前核对（2026-11-10）

对照第二阶段产物核对本文的读数与配置表述，确认三处需要修正或补充说明：

- 第 1 节“真实故障节点被观测时的部分观测 Top-1 为 87.68%–94.78%”应改为 89.19%–94.78%；87.68% 是 35 个观测节点下**总体**部分观测 Top-1，不是被观测子集。其余读数（完整 Top-1 92.54%、未观测覆盖率 94.13%–97.78%、未观测单节点 Top-1 27.17%–70.00%、区域 7.15–8.19 个节点）与产物一致。
- 第 3.2 节的两个 “(1.0,0.3,0.1)” 权重相同但损失不同，应分别记为“原始 A tau1x（三项损失，第三项为图平滑）”与“第一阶段区域配置（第三项为区域概率）”，否则会被误读为重复配置。
- 第 4.2 节固定 \(\beta_{\mathrm{obs}}=0.05\)，而第二阶段选定配置使用 \(\beta_{\mathrm{obs}}=0.1\)。因此该组中 \(\sigma=1.0,\beta_{\mathrm{miss}}=0.4\) 的单元不是当前基线的重复，而是“更尖锐的观测目标”下的新配置。执行时把 \(\beta_{\mathrm{obs}}=0.1,\beta_{\mathrm{miss}}=0.4,\sigma=1.0\) 作为独立对照单元一并训练，避免把 \(\beta_{\mathrm{obs}}\) 的变化误记为 \(\beta_{\mathrm{miss}}\) 或 \(\sigma\) 的效应。

执行约定：多种子复核使用种子 342、343、344；种子 343 与 344 的排序温度仍固定为 0.0040640985（不逐种子重新标定），以免把温度变化与种子效应混淆；多种子比较只在验证集进行，测试集保持每种配置仅在种子 342 上评价一次的既有口径。

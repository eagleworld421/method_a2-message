# GReF 候选拓扑单调性检查方案

## 1. 范围与响应量

- 日期：2026-11-03；任务标识：GREF-004。
- 使用 A、B 已保存最佳模型的全部测试预测，各 228 条，共 456 个模型—事件记录；两组共享的参数族不视为 456 个独立物理工况。
- 每条事件检查全部 38 个故障候选，排除正常候选，不重新训练或修改权重。
- 候选能量为统一标准化坐标中 $D(X,\widehat S_k)$ 的有效元素均方差；响应重构误差为 $\operatorname{SmoothL1}(\widehat S_k,S_k)$ 的有效元素平均值，逐候选计算，不将事实观测作为重构目标。
- 两个量分别分类、统计和作图；图中节点编号为保存数组的候选索引，不冒充 IEEE 母线名。

## 2. 拓扑与分类

将保存的有向边去重为无向拓扑，检查连通性和树结构。距离为真实故障点到候选节点的最短路径跳数，不解释为线路长度、阻抗或地理距离。外向边是由距离较小端指向距离较大端的边。

对每条事件与每个响应量，记 38 个候选数值跨度为 $R=\max_kv_k-\min_kv_k$。主判定容差为 $\tau=\max(10^{-8},16\epsilon_{32}\max_k|v_k|,0.01R)$。

- 严格逐边增长：全部外向边均满足 $v_{child}-v_{parent}>\tau$。
- 非递减但含平台：没有小于 $-\tau$ 的变化，且至少存在一个绝对变化不超过 $\tau$ 的外向边。
- 存在向外下降：至少一条外向边满足变化小于 $-\tau$。

以上三类互斥且覆盖全部事件。另报告以下可重叠现象：

- 平台出现：至少一条外向边绝对变化不超过 $\tau$，允许与下降共存。
- 同跳数分支差异：某个非零距离层至少含两个节点，其最大值与最小值之差大于 $\max(\tau,0.1R)$。

补充统计包含错误候选之间的 Spearman 相关、跨距离候选对顺序违反比例、逐边下降和平台比例、距离层均值非递减情况。跨距离候选对排除真实节点，只比较距离严格不同的两个错误候选。距离层均值的上升不能替代逐边单调性。

敏感性分析使用相同数值下界，将相对平台容差改为 0、0.1%、1%、5%，分支阈值保持 10%。这些是描述性阈值，不是统计显著性标准，也不用于调参。

## 3. 案例选择与可视化

对每个响应量的严格增长、平台出现、向外下降和分支差异分别选择至多三个实际案例。优先从 A、B 各选一个严重度中位数附近案例，再从合并候选中选择 75% 分位附近的未选案例，尽量避免重复的模型—参数族；分类内部的三个案例不重复。严重度分别为最小外向增量、平台边比例、最大相对下降幅度和最大同层相对跨度。

若某类不足三个，仅展示实际数量；若为零，不生成虚构案例。不同类别可以选择同一事件，明确它们可重叠。

每个响应量、每个存在案例的情况生成一张三行案例图，每行包含固定布局的拓扑着色图和跳数—数值散点图。图上标出真实故障点、全部候选数值分布、外向边变化及重点违反位置。另生成全部事件的情况占比总览。只对选中案例生成详细图，不为全部事件生成逐事件图。

全部事件统计、全部候选数值及选中案例保存在 `code/method-a2/output/gref/topology-analysis-20261103/`；图片提供 PNG 和 SVG。逐模型及合并比例均以对应全部测试事件为分母，并说明依赖性。执行结论归入 `docs/project/reports/`，不修改既有预测产物。

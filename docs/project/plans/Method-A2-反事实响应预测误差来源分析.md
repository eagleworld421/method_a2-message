# Method-A2 实验计划：反事实响应预测误差来源分析

## 实验名称

State Extraction Error vs Candidate-conditioned Generation Error
Analysis

------------------------------------------------------------------------

# 1. 实验背景

当前 Method-A2 的核心任务为：

给定事实事件观测：

\[ X_m \]

生成该事件所有候选故障位置下的反事实响应族：

\[ `\mathcal `{=tex}S_m\^{CF} =
{S\^{CF}*{m,k}}*{k`\in`{=tex}`\mathcal `{=tex}K_m} \]

其中：

\[ S\^{CF}\_{m,k} =
`\psi`{=tex}(G_m\^{true},H_m,C_m,`\operatorname{do}`{=tex}(K_m=k)) \]

对于同一个事件：

-   (H_m)：运行背景状态；
-   (C_m)：除故障位置外的事件条件；

在候选轴变化时保持不变。

当前已有模型能够实现：

\[ X_m`\rightarrow`{=tex}`\widehat{\mathcal S}`{=tex}\^{CF}\_m \]

但是仍存在响应预测误差：

\[ d_S(`\widehat `{=tex}S\^{CF}*{m,k},S\^{CF}*{m,k}) \]

需要确认当前误差主要来源：

1.  共享状态提取不足；
2.  候选位置条件到响应变化的生成能力不足。

------------------------------------------------------------------------

# 2. 实验目的

本实验目标：

分析当前反事实响应预测误差来源，为后续是否引入共享状态表示 (U)
提供实验依据。

本实验不设计新的模型结构，不加入新的损失函数，仅构造不同信息条件下的预测任务并保存完整实验数据。

------------------------------------------------------------------------

# 3. 实验设计

## Experiment 1：Current Baseline Response Prediction

### 目的

记录当前标准任务下模型的反事实响应预测能力。

### 输入

当前 Method-A2 标准输入：

\[ X_m \]

### 输出

\[ `\widehat `{=tex}S\^{CF}\_{m,k} \]

覆盖：

\[ k`\in`{=tex}`\mathcal `{=tex}K_m \]

### 保存内容

必须保存：

-   模型配置；
-   数据版本；
-   输入定义；
-   输出预测；
-   真实响应；
-   候选集合；
-   每事件预测结果。

------------------------------------------------------------------------

## Experiment 2：Oracle Condition Response Prediction

### 目的

构造已知事件物理条件情况下的响应预测实验。

### 输入

真实事件条件：

\[ H_m,C_m \]

以及候选：

\[ k \]

### 输出

\[ `\widehat `{=tex}S\^{CF}\_{m,k} \]

### 保存内容

必须保存：

-   使用的真实物理条件；
-   候选位置；
-   预测响应；
-   真实响应；
-   每事件全部候选结果；
-   模型参数；
-   训练过程记录。

------------------------------------------------------------------------

## Experiment 3：Candidate-conditioned Response Prediction

### 目的

在事件条件固定情况下研究候选位置变化本身的响应生成难度。

### 输入

\[ H_m,C_m,k \]

### 输出

\[ `\widehat `{=tex}S\^{CF}\_{m,k} \]

### 保存内容

必须保存：

-   每个事件；
-   每个候选；
-   输入条件；
-   预测响应；
-   真实响应；
-   误差结果；
-   模型训练配置。

------------------------------------------------------------------------

# 4. 数据范围要求

所有实验必须保持：

-   相同数据集；
-   相同事件划分；
-   相同测试集；
-   相同候选集合；
-   相同响应定义。

禁止由于实验条件变化引入额外数据差异。

------------------------------------------------------------------------

# 6. 实验执行要求

1.  不修改 Method-A2 正式代码结构。
2.  不加入共享状态模块。
3.  不加入新的 ranking loss。
4.  不进行针对性调参。
5.  保持实验之间公平比较。

------------------------------------------------------------------------

# 7. 结果保存与反馈要求

实验完成后，必须保存完整实验数据。

提交：

1.  实验代码修改记录；
2.  实验配置文件；
3.  模型 checkpoint；
4.  测试预测结果；
5.  指标文件；
6.  数据路径；
7.  实验日志。

重点：

不要只返回实验结论。

必须保留完整预测数据：

\[ {X_m,H_m,C_m,k,S\^{CF}*{m,k},`\widehat `{=tex}S\^{CF}*{m,k}} \]

后续基于完整实验数据进一步判断：

-   是否需要共享状态表示；
-   共享状态应承担什么作用。

------------------------------------------------------------------------

# 8. 注意事项

本实验阶段不讨论：

-   \(U\) 的具体形式；
-   encoder 结构；
-   decoder 结构；
-   TCN/GNN/Transformer；
-   loss 设计。

实验目标仅为：

建立不同信息条件下的反事实响应预测基准数据。

实验完成后，再讨论共享状态表示与后续模型设计。

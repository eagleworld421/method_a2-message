# Method-A2 主要实验数据集登记

登记日期：2026-11-06。本文为持续维护的数据集入口，当前登记六个主要实验数据集，不包含历史小规模数据、流程测试数据及空目录。

## 1. 名词与共同口径

- 数据集名称指实际目录名，路径均相对项目根目录；数据目录统一为 `code/method-a2/data/`。
- 电阻范围指生成配置中的抽样区间，单位为 Ω，不表示实际样本恰好覆盖两个端点。
- S0 指完整输入拓扑与完整节点观测的基础情形。以下五套数据均为单相接地故障，包含正常样本；每套含 40 个故障事件族，同族共享工况和故障参数、改变故障位置，候选相关随机扰动关闭。
- S1 指推理时屏蔽输入拓扑边；既有实验不改变电压观测和物理签名，不执行物理断线仿真。
- S2 指推理时屏蔽部分节点观测；既有实验保留完整拓扑及故障候选集合。
- S1/S2 是在基础数据上施加的实验处理，不因施加掩码而自动构成独立生成的数据集。

## 3. 维护与调用规则

1. 后续实验若新增数据集，必须同步维护本文，至少登记名称、实际路径、电阻范围、算例及特殊处理；已有数据的登记属性发生变化时同步修订。新增独立保存的 S1/S2 派生数据集时，应注明基础数据来源与处理方式。
2. 实验调用数据集前，必须依据本文确认名称、实际路径、电阻范围、算例及特殊处理，并核对实际元数据与实验配置；未登记或存在不一致时，先完成登记或澄清，再执行实验。S1/S2 掩码、划分及归一化以本次实验明确记录的配置为准，不直接沿用其他运行的设置。

# 研究目标与总体思路

## 一、总体研究目标

本研究的总体目标是：

> 通过反事实物理响应构建一种可解释、可靠并适用于复杂运行环境的故障诊断方法。

该方法不把故障诊断仅处理为直接类别预测，而是针对不同故障假设生成相应的物理响应，并根据这些响应对实际观测的解释能力完成故障检测、故障定位和结果判断。

## 二、基本技术思路

对于一个实际观测事件，方法枚举可能的故障位置或故障假设，并生成每个候选假设对应的反事实物理响应：

$$
S_k=\Psi(G,\operatorname{do}(F=k),H).
$$

实际观测与各候选响应进行比较，形成候选诊断分数，并据此选择最能解释观测的故障假设。

这种思路的核心是：

1. 故障诊断结果对应明确的物理假设；
2. 每个候选故障都有可检查的反事实响应；
3. 候选之间的比较具有物理含义；
4. 模型输出可以通过响应、残差、候选排序和物理约束进行解释。

## 三、可解释性目标

可解释性主要来自反事实响应链条：

- 方法明确说明“如果故障发生在候选位置，会产生什么响应”；
- 方法可以展示实际观测与各候选响应之间的差异；
- 方法可以给出真实候选、错误候选和最难错误候选之间的物理比较；
- 最终诊断结果能够追溯到候选假设及其响应解释，而不是只输出一个无法解释的类别概率。

## 四、可靠性目标

可靠性不仅指理想条件下的定位准确率，还包括在信息受损、物理差异减弱或系统条件变化时，方法仍能给出稳定、可比较并且能够识别证据不足的诊断结果。

可靠性验证应覆盖：

- 正确拓扑和完整观测；
- 拓扑信息错误；
- 部分观测或观测节点缺失；
- 未参与训练的拓扑或网络结构变化；
- 高阻故障和较弱故障响应；
- 必要的组合困难场景。

这些场景用于判断方法是否依赖固定拓扑、节点编号、完整观测或强故障信号。
### S0：正确拓扑与完整观测基线

S0 采用正确拓扑和完整观测，用于建立理想条件下的反事实响应生成、候选比较、故障检测和故障定位基线。S0 只能作为基础参考，不能代表复杂运行环境下的最终可靠性。

### S1：拓扑信息错误

S1 模拟开关状态、线路连接关系或拓扑台账存在错误的情况。真实物理响应和反事实监督仍由真实拓扑生成，模型接收的则是可能错误的观测拓扑。该场景用于检验方法能否区分“故障假设错误”和“拓扑上下文错误”，并评估错误拓扑对候选响应预测、故障检测和故障排序的影响。

### S2：部分观测

S2 模拟量测缺失、关键节点未被观测或随机节点掉线。完整物理响应仍作为物理参考，但诊断评分只能在观测掩码覆盖的部分上计算，缺失值不能被当作真实零值。该场景重点检验方法能否在证据减少时保持合理的候选比较，并避免把“没有观测到异常”误判为“系统无故障”。

### S3：跨拓扑变化

S3 将训练拓扑与测试拓扑或拓扑族严格分离，用于检验方法是否学习了可迁移的故障物理规律，而不是记忆固定节点编号、邻接关系、线路数量或馈线规模。正式结论必须建立在互斥拓扑实例或拓扑族划分上，不能由单一拓扑内部随机划分替代。

### S4：高阻故障与弱故障响应

S4 提高故障阻抗或采用其他会减弱故障响应的条件，使真实候选与错误候选之间的物理差异变小，并增加与正常状态混淆的风险。该场景用于检验故障检测、候选排序、不确定性表达和证据不足时的拒识能力。S4 应与 S0–S3 组合使用，而不应被简化为一个孤立的高阻故障数据集。

S1–S4 共同构成从理想条件到复杂条件的可靠性验证链：S1 检验拓扑上下文污染，S2 检验观测证据减少，S3 检验网络结构变化，S4 检验故障物理信号减弱。每个场景都应保留真实拓扑、观测拓扑、观测掩码、故障条件和场景参数，以支持分层评价和失效解释。

## 五、复杂环境适用性目标

复杂环境下，运行状态、拓扑、观测条件和故障表现可能同时变化。方法需要在保留物理语义的前提下处理这些变化，而不能仅依赖固定场景中的统计相关性。

因此需要：

- 区分真实拓扑与部署时获得的拓扑信息；
- 显式记录观测掩码和信息缺失；
- 保留候选响应的物理条件和候选语义；
- 对不同工况、故障类型、阻抗和拓扑条件进行分层评价；
- 在证据不足时输出不确定或拒识结果，而不是强行给出过度确定的故障位置。

## 六、Method-A2 的位置

Method-A2 是实现上述总体目标的一条方法分支，当前重点研究：

- 事实观测与完整反事实响应族之间的关系；
- 如何根据部署可见输入预测候选响应；
- 候选响应预测误差如何影响最终故障排序；
- 误差来自状态信息提取、候选响应映射还是其他环节。

这些内容服务于总体目标，但不等同于总体目标本身。

当前 A2 的 S0、单拓扑、全观测实验属于方法分支的基础验证阶段。它们可以检验反事实响应链条和候选预测机制是否成立，不能单独证明方法已经适用于全部复杂环境。

## 七、研究内容的层次关系

本研究应保持以下层次：

1. **总体目标**：反事实物理响应驱动的可解释、可靠、复杂环境故障诊断；
2. **方法框架**：生成候选反事实响应，并通过观测一致性完成诊断；
3. **方法分支**：Method-A1、Method-A2 及其他候选实现；
4. **基础验证**：信息、数据契约、响应预测和候选排序验证；
5. **可靠性验证**：拓扑错误、部分观测、跨拓扑、高阻故障及组合场景；
6. **最终评价**：解释性、定位可靠性、复杂环境适用性和证据不足时的行为。

可辨识性实验、误差来源分析和候选响应预测实验属于支撑性验证，不能替代总体研究目标。

本文只规定总体目标、基本技术思路和方法层次，不指定具体网络结构、表示空间、损失函数或最终实现方案。

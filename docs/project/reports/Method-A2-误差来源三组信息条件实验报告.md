# Method-A2 反事实响应预测误差来源分析实验报告

## 1. 执行范围与运行标识

本文报告按《Method-A2-反事实响应预测误差来源分析》执行的三组实验的完整结果。实验设计、数据范围要求、产物要求与执行约束均按该文档执行，未新增模型结构、未加入共享状态模块、未加入 ranking 或 contrastive 损失、未做针对性调参、未改动既有 Method-A2 代码文件。

- 运行标识：`esrun-20260922-error-source`
- 产物根目录：`code/method-a1/output/error-source/esrun-20260922-error-source`
- 日志目录：`code/method-a1/logs/error-source/esrun-20260922-error-source`
- 执行脚本：`code/method-a1/scripts/run_error_source_experiments.py`
- 审计脚本：`code/method-a1/scripts/audit_error_source_results.py`
- 测试文件：`code/method-a1/tests/test_error_source_experiments.py`（11 项，全部通过；方法目录全量测试 201 项全部通过）
- 计算设备：cuda

## 2. 三组实验的信息条件

三组实验的差别只在输入信息条件，其余全部相同。

- Experiment 1（Current Baseline Response Prediction）：输入为部署可见事实响应 $X_m$、候选物理特征、拓扑与掩码；模型为仓库既有部署 predictor 的 checkpoint，只做推理，不重新训练。
- Experiment 2（Oracle Condition Response Prediction）：输入为真实事件条件 $(H_m,C_m)$ 与候选物理特征；同一事件的全部候选共享同一条件向量。
- Experiment 3（Candidate-conditioned Response Prediction）：输入为 $(H_m,C_m,k)$；条件向量按候选拼接候选身份单热编码后再编码，使候选轴信息沿共享解码路径进入响应生成。

三组实验共用同一数据集、同一事件划分、同一测试集、同一候选轴与同一响应定义，核对结果如下。

- 数据集：`paired-v1-ieee13-1600-seed342`，1600 事件，16 节点，17 候选，响应形状 $[N,T,F]=[16,12,6]$。
- 划分：train 1120、val 240、test 240，由数据集自身划分文件给出，三组实验完全一致。
- 测试集事件索引：三组实验保存的 `event_indices` 与数据集 `test_idx` 逐项相同。
- 候选轴：17 项，序号 0 至 15 为故障母线候选，序号 16 为正常候选。
- 响应定义：正式 $d_S$，节点—特征权重 $1/(s_{n,f}^2+10^{-8})$，分母为掩码元素数 $N\cdot T\cdot F$。

## 3. 条件向量定义

条件向量严格由事件元数据中的真实生成参数构造，不含真实故障位置。

- $H_m$：15 个负荷乘子，键顺序取数据中出现顺序，即 `611、634a、634b、634c、645、646、652、670a、670b、670c、671、675a、675b、675c、692`。
- $C_m$：故障类型单热编码（5 类）、`log1p(true_impedance)`、`fault_delay_steps`，共 7 维。
- 条件向量维度为 22 维，只用训练划分的均值与标准差标准化，统计量已写入各实验的 `config.json`。
- 未标准化条件表按事件逐行保存在 `conditions_raw.csv`，字段名与事件 ID 一一对应。

## 4. 实现决策与运行期校验

按文档第 6 节的约束，本次实现只复用既有 Method-A2 的候选条件编码器，解码头为与既有头同层数、同隐藏宽度、同解码形状的本地实现，唯一差别是条件输入支持逐候选形状 $[B,K,C]$，因此既有头模块的接口不需要改动。该差别已写入各实验 `config.json` 的 `model_parameters.local_modules`。

由于条件臂的输入必须严格为 $(H_m,C_m)$ 或 $(H_m,C_m,k)$，事实响应 $X_m$ 不得进入前向。实现方式与校验结果如下。

- 条件臂把观测替换为冻结的常量观测张量（`frozen_observation` 缓冲区），结构中不读取传入的观测张量。
- 运行期执行 X 无关性校验：同一批次分别以零观测与真实观测前向，输出最大差 Experiment 2 为 $0.000\times10^{0}$、Experiment 3 为 $2.608\times10^{-8}$（float32 舍入量级），该值已写入各实验 `metrics.json` 的 `x_independence_max_abs_output_diff`。
- 运行期执行条件置换探针：把条件向量替换为另一事件的条件向量，输出必须改变。Experiment 2 的四对置换响应最大改变为 $7.0718\times10^{-3}$ 至 $3.8108\times10^{-2}$，Experiment 3 为 $3.2235\times10^{-2}$ 至 $5.1594\times10^{-2}$，证明条件臂确实在使用条件信息。
- 值得记录的一个实现细节：既有候选条件编码器在观测为零时的时序输出仍与输入取值有关（偏置经非线性后参与卷积），因此简单置零不足以实现严格的 X 无关；本次改用冻结常量观测张量并在运行期强制校验。

## 6. 与常数族基线的对照

为判断条件臂是否真的提供了有效信息，在同一测试集与同一 $d_S$ 口径下计算“与事件无关的常数族”基线：取训练集事件的候选响应均值作为 17 项参数的预测族，测试集族级 $d_S$ 均值为 $9.673326\times10^{-3}$，中位数为 $1.289017\times10^{-3}$。

- Experiment 1：均值比 $0.793$，中位数比 $0.888$。
- Experiment 2：均值比 $0.857$，中位数比 $1.573$。
- Experiment 3：均值比 $0.784$，中位数比 $1.200$。

即：三组实验在均值口径都优于常数族，但在中位数口径只有 Experiment 1 优于常数族；两个条件臂的中位数误差反而高于常数族，说明条件臂在典型事件上没有达到常数族的水准，其均值优势来自对少数大误差事件的处理，而不是整体族级精度。

## 7. 结果判定

### 7.1 候选间结构保真度

逐事件计算候选间距离剖面（17 个候选两两之间的距离），再比较真值剖面与预测剖面。

- Experiment 1：剖面变异系数比 $6.334$，剖面对齐相关系数中位数 $0.423$，候选方向能量比中位数 $0.488$，剖面负相关事件比例 $0.025$。
- Experiment 2：$5.640$、$0.390$、$0.281$、$0.046$。
- Experiment 3：$3.003$、$0.438$、$0.269$、$0.017$。

真值的候选间距离剖面变异系数中位数为 $0.108$，候选方向能量（真值）中位数为 $2.797\times10^{-2}$。条件臂的剖面抖动更小，但其候选方向能量比由基线的 $0.488$ 降至 $0.281$ 与 $0.269$，即给出真实 (H_m,C_m) 反而使候选对比度更弱。三组实验的剖面对齐相关系数几乎相同（$0.423$、$0.390$、$0.438$），说明提供真实条件没有改善候选间结构的重建质量。

### 7.2 误差构成

按逐候选平均偏移与去偏移残差分解族级误差。

- Experiment 1：候选无关偏移占比 $0.3444$，偏移均值 $2.643510\times10^{-3}$，总误差均值 $7.674937\times10^{-3}$。
- Experiment 2：$0.4374$，$3.626516\times10^{-3}$，$8.291738\times10^{-3}$。
- Experiment 3：$0.4536$，$3.439545\times10^{-3}$，$7.583605\times10^{-3}$。

条件臂的候选无关偏移占比更高，即条件臂把更多的误差放在“所有候选一起偏”的分量上，与 7.1 中候选对比度更弱的结论一致。

### 7.3 定位指标

按文档与既有口径，评分采用 $R_{m,k}=d_S(X_m,\widehat S^{CF}_{m,k})$，只在 16 个故障候选上取 $\arg\min$。

- Experiment 1：Top-1 $0.1625$，Top-3 $0.4500$，平均真实 rank $4.808$，随机基线 Top-1 $0.0625$。
- Experiment 2：Top-1 $0.1458$，Top-3 $0.3542$，平均真实 rank $4.700$。
- Experiment 3：Top-1 $0.2292$，Top-3 $0.4958$，平均真实 rank $3.683$。

候选轴散布（预测族在候选轴上的极差绝对值）中位数：Experiment 1 $0.0335$，Experiment 2 $0.0224$，Experiment 3 $0.0225$；$p95$ 分别为 $0.1496$、$0.1186$、$0.1649$。候选轴信息确实进入预测，但幅度低于真值所需的判别间隔。

### 7.4 对误差来源的判定

按《Method-A2-反事实响应预测误差来源分析》建立的“不同信息条件下的基准数据”这一目标，本次三组实验给出的判定如下。

- 给出真实 $(H_m,C_m)$ 并没有降低族级误差：Experiment 2 的均值与中位数都高于 Experiment 1，且中位数高于常数族基线。因此不支持“当前误差的主要来源是共享状态提取不足”这一解释。按该文档的判定逻辑，若原因是状态提取不足，则已知真实状态时应出现明显下降，而实测未出现。
- 候选条件化带来的是定位指标的改善与族级误差的轻微改善，而不是候选结构的改善：Experiment 3 的 Top-1 由 $0.1625$ 提升到 $0.2292$，平均真实 rank 由 $4.808$ 降到 $3.683$，族级均值由 $7.674937\times10^{-3}$ 降到 $7.583605\times10^{-3}$；但候选方向能量比反而从 $0.488$ 降到 $0.269$，剖面对齐相关系数基本不变，候选无关偏移占比从 $0.344$ 升到 $0.454$。
- 误差既包含族级偏移也包含候选结构残差，两者在本次测量中都无法由真实条件消除：候选无关偏移占比在三组实验中介于 $0.344$ 与 $0.454$ 之间，去偏移残差始终占主导。
- 逐候选结果说明条件臂的能力分布不均：在候选 1、2、4、11、16 上条件臂明显更优（例如候选 11 由 $9.110111\times10^{-3}$ 降到 $4.690956\times10^{-3}$），但在候选 3、5、6、7、8、9、12、13、14、15 上反而更差（例如候选 6 由 $6.918752\times10^{-3}$ 升到 $1.021438\times10^{-2}$）。这说明由真实条件到响应的映射并非处处容易学习。

## 8. 产物与可核对项

每组实验目录下均保存文档第 5 节要求的全部文件，审计确认 8 项文件全部存在。

- `config.json`：实验名、数据版本、随机种子 342、模型参数与条件布局、输入与输出变量定义、训练参数（Adam、lr $10^{-3}$、batch 16、epochs 100、patience 20、min_delta $10^{-4}$、grad clip 5.0）、条件标准化统计量、耗时与训练摘要。
- `prediction_results.npz`：`event_indices`、`event_ids`、`candidate_ids`、`true_location`、`S_cf_true`、`S_cf_pred`、`x_obs`、`condition_vector`、`condition_vector_raw`、`d_S_per_pair`，形状为 $[240,17,16,12,6]$。
- `metrics.json`：overall、event-level 与 candidate-level 三层误差，候选间结构指标，候选轴散布，条件置换探针，X 无关性校验值，定位指标与划分规模。
- `metrics_candidate.csv`：逐候选 `mean_dS`、`median_dS`、`p90_dS`。
- `metrics_event.csv`：逐事件 `d_S` 与真实位置。
- `conditions_raw.csv`：逐事件未标准化条件表，字段名与事件 ID 对应。
- `train_log.csv` 与 `eval_log.jsonl`：逐轮训练与验证损失、耗时、阶段评价记录。
- `checkpoint/model.pt`：Experiment 2 与 Experiment 3 的模型参数；Experiment 1 复用既有 checkpoint，不重新训练，因此该目录不含新 checkpoint，其来源路径记录在 `config.json` 中。

文档第 7 节要求的“完整预测数据”指 $X_m$、$H_m$、$C_m$、$k$、$S^{CF}_{m,k}$ 与 $\widehat S^{CF}_{m,k}$ 的配对数据。本次产物按事件索引对齐保存，$X_m$ 在 `x_obs` 中，$H_m$ 与 $C_m$ 在 `condition_vector_raw` 与 `conditions_raw.csv` 中，$k$ 由候选轴序号给出，真实响应与预测响应分别在 `S_cf_true` 与 `S_cf_pred` 中。

## 9. 边界与限制

- 本次三组实验均为单随机种子（342）、单数据划分、单拓扑（IEEE13 家族）、全节点观测的 S0 条件；不构成对 S1 错误拓扑、S2 部分观测、S3 跨拓扑与 S4 高阻域的推断。
- 条件向量是 $(H_m,C_m)$ 的一种编码，包含 15 个负荷乘子、故障类型、故障阻抗与故障时刻；它不包含故障前电压初值等由运行工况隐式决定的量。因此本次 Experiment 2 与 Experiment 3 给出的是“给定这组真实标量条件”的上界，而不是“给定全部生成所需状态”的绝对上界。
- 条件臂的解码头为与既有头同宽同深的本地实现，条件输入支持逐候选形状；这一点是 Experiment 3 能够把候选轴信息沿共享解码路径传入的必要条件，已记录在 `config.json` 中，不属于对既有 Method-A2 代码的修改。
- 条件臂的训练与早停口径为同一套固定配置（Adam、lr $10^{-3}$、batch 16、epochs 100、patience 20），实际上均跑满 100 轮且未触发早停（Experiment 2 最佳轮次 82，validation 响应距离 $3.812434\times10^{-3}$；Experiment 3 最佳轮次 92，$3.278082\times10^{-3}$）。Experiment 1 复用既有 checkpoint（最佳轮次 95，记录的验证损失 $5.959256\times10^{-3}$），该值与两个条件臂的验证损失使用不同的损失实现路径，不能直接比较，因此本文的所有对照都以同一测试集上的正式 $d_S$ 口径与同一常数族基线为准。
- 本文只报告实测结果与判定，不讨论 $U$ 的具体形式、encoder 与 decoder 结构、TCN/GNN/Transformer 选型与损失设计，符合文档第 8 节的范围约束。

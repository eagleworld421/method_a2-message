# Method-A2 误差来源公式核验与实验证据审计

## 1. 范围与结论摘要

本文核验一份题为“Method-A2 实验分析任务：定位反事实响应预测误差来源”的分析文稿，逐条检查其中的前提、符号与公式是否与本仓库既有文档、代码与实验产物相符；并在此之上，用既有数据与既有模型 checkpoint 做只读测量，回答该文稿提出的“误差来自状态提取还是候选生成”这一问题在两个层面上的可判定性。

结论分三部分。

第一，**记法层面**。该文稿前两式的物理事实与反事实监督记法与《Method-A2-核心公式》第 2 节完全一致；候选集合、部署可见输入、监督目标为整族候选响应、$d_S$ 的性质、模型输入输出等前提均与既有文档和代码一致；其“注意事项”中“不要直接假设 $U$ 有效”“不要只比较 $MSE$”“必须同时分析绝对误差、候选间物理关系与最终排序”等约束与仓库既有规范同向。

第二，**错误层面**。文稿中有 5 处不成立或与实现不符：误差加法分解 $E_{total}=E_{state}+E_{candidate}$ 不是恒等式，在平方量口径下缺少交叉项；候选集合归一写作 $|\mathcal K|$ 与逐事件候选掩码的事实不符；文稿已声明 $d_S$ 为平方量却在全篇以 $MSE$ 与均方混写，未声明所用口径；把模型描述为隐含完成 $X_m\to U_m\to\{S^{CF}_{m,k}\}$ 与实现不符；把当前反事实响应族描述为“已经能够生成较准确”与实测排序指标不符。

第三，**可判定性层面**。文稿要求的 $E_{state}$ 与 $E_{candidate}$ 正式分解在现有数据上不可完成，因为 $U_m=(H_m,C_m)$ 不是数据中可观测的变量，其定义依赖一个尚未指定的提取算子。但既有数据已经足以否定“误差主要来自状态提取”这一候选解释：误差的主要损失发生在候选间判别上，而不是族级水平上；且模型的族级误差已低于训练集中“事实响应互为最近邻的事件对”之间的族离散度，而后者只是给定 $X$ 的族条件方差的上界。

## 2. 与《Method-A2-核心公式》逐条核对的结果

### 2.1 相符项

以下前提与符号经核对成立，可以作为后续分析的基础。

- 物理事实生成式 $X_m=\psi(G^{true}_m,H_m,C_m,K^{true}_m)$ 与反事实监督生成式 $S^{CF}_{m,k}=\psi(G^{true}_m,H_m,C_m,\operatorname{do}(K_m=k))$ 与《Method-A2-核心公式》第 2 节逐字一致。
- $H_m$ 为运行工况与负荷状态、$C_m$ 为同一事件在候选轴上保持不变的物理条件（故障类型、相别、阻抗、时刻）的归并记法，与同一文档第 3 节一致。
- 候选故障母线 $k$ 的取值口径一致：真实数据中候选轴共 17 项，序号 0 至 15 为 16 个故障母线候选，序号 16 为正常候选（`is_no_fault` 指示位为 1 的候选序号为 `[16]`）。
- “部署侧前向的输入不含真实故障母线”这一前提成立：既有 `teacher.pt` 的学生前向只接收观测、拓扑、候选物理描述、节点物理描述与两个掩码，签名中不存在真实阻抗与真实位置参数。
- 推理评分式与复核口径一致：本报告按 $R_{m,k}=d_S(X_m,\widehat S^{CF}_{m,k})$ 复算，得到 Top-1 $=0.1625$、Top-3 $=0.4500$、平均真实排名 $=4.8083$、16 个故障候选下的随机基线 Top-1 $=0.0625$，与既有报告中 teacher 变体的 `top1_fault_student = 0.16249999403953552`、`topk_fault_student = 0.44999998807907104`、`avg_true_rank_student = 4.808333396911621` 逐项一致。
- 实验 A 的候选间相对误差思路与既有产物可衔接：既有 I2 baseline 已经产出逐候选 `mean_dS`、`median_dS`、`p90_dS`，可直接支持该文稿“必需信息 2：候选级误差”。

### 2.2 不相符项

以下 5 处需要修正后该文稿才能作为正式分析依据。

（1）误差加法分解不是恒等式。文稿写出 $E_{total}=E_{state}+E_{candidate}$。在平方量口径下，预测与真值之差可分解为“候选无关分量”与“候选相关分量”，但两者之和的平方和必然带有交叉项，除非两者在加权内积意义下正交，否则交叉项不为零。实测（配对 `paired-v1-ieee13-1600-seed342` 测试集 240 事件，既有 `teacher.pt` 学生前向）在加权均值口径下逐事件交叉项最大为 $2.020466\times10^{-1}$，在未加权均值口径下逐事件交叉项最大为 $3.709126\times10^{-1}$。因此该式只能读作近似，且必须写明所用口径与交叉项处理方式。

（2）该分解的具体数值随口径剧烈变化，文稿未声明口径。同一份预测下，若“候选无关分量”取加权均值口径，则该项占族级总误差的 $0.0064$；若取未加权均值口径，则占 $0.3444$。同一分解的结论在两种口径下相差两个数量级，因此不声明口径的 $E_{state}$ 数值不构成证据。

（3）候选集合归一的记号与事实不符。文稿实验 A 的全局误差式写作 $\frac{1}{|\mathcal K|}\sum_k d_S(\hat S_k,S_k)$。既有数据中候选集合由逐事件候选掩码决定，当前 S0 数据全部事件掩码为全 1 且候选轴一致，故此时 $|\mathcal K_m|=17$ 对所有事件成立；但正确的写法仍应是 $\frac{1}{|\mathcal K_m|}\sum_{k\in\mathcal K_m}$，否则在掩码不全为 1 的场景下该式不成立。

（4）量纲口径混写。文稿已经写明 $d_S$ 是平方量，但在全篇以 $MSE$ 称呼 $d_S$，且未在 $d_S(\cdot,\cdot)$ 与 $\sqrt{d_S(\cdot,\cdot)}$ 之间作出区分。实测两种口径差别很大：同一预测下族级误差的均方口径中位数为 $1.155938\times10^{-3}$，开方口径中位数为 $3.384030\times10^{-2}$。既有实验记录中两种口径同时存在（I2 的逐事件族统计使用开方口径，`response_distance_student` 使用均方口径），因此任何跨实验比较都必须先声明口径。

（5）“模型隐含完成过程 A 与过程 B”与实现不符。文稿把当前模型描述为隐含完成 $X_m\to U_m$ 与 $(U_m,k)\to S^{CF}_{m,k}$ 两步。实现中共享编码器把观测与拓扑编码为节点表示，同一节点表示被复制到全部候选，候选物理描述经匹配注意力与候选嵌入直接进入共享解码器；不存在模块级的 $U_m$，也不能把中间量的误差归到“状态提取”名下。此外数据中不存在 $(H_m,C_m)$ 的直接标签，只有 `block_id`、`load_multipliers`、`fault_class`、`true_impedance`、`fault_delay_steps` 等生成参数的可观测代理，因此实验 B 与实验 C 的“输入 $H_m,C_m$”必须落在这些代理字段上。

（6）该文稿对当前误差来源的起点存在矛盾。文稿称模型“已经能够生成较准确的反事实响应族”，并以“只需判断误差来源”为前提；但实测中 $80.4\%$ 的测试事件在预测族下的真实候选间隔为负，Top-1 仅 $0.1625$（随机基线 $0.0625$）。该前提需要改写为“响应族的整体水平已接近数据可支持下界，但候选间判别大幅退化”，否则后续误差分解会建立在错误的起点上。

### 2.3 不构成错误但需显式声明的隐含假设

- 文稿把共享状态取为 $U_m=(H_m,C_m)$，即不含 $K^{true}_m$。在此定义下 $X_m\to U_m$ 不是单值的：$X_m$ 是 $(H_m,C_m,K^{true}_m)$ 的函数，同一 $(H_m,C_m)$ 配不同真实位置会产生不同 $X_m$。因此按该文稿的写法，$E_{state}$ 必须显式依赖一个尚未指定的提取算子 $\widehat U=\phi(X)$，否则 $E_{state}$ 无定义。
- 该文稿同时要求“不要直接假设 $U$ 有效”，但 $E_{total}=E_{state}+E_{candidate}$ 这一写法本身已经预设了 $U$ 这一中间变量存在且可通过其误差归因，两者需要统一。

## 3. 实验 A 所需数据与指标的现存状况

按该文稿第 7 节的数据收集要求逐条核对，结果如下。

- 数据文件：全部存在。来源为 `code/method-a1/data/pi-response/paired-v1-ieee13-1600-seed342`，含事实响应 `X_obs.npy` 形状 $[1600,16,12,6]$、候选响应族 `paired_response.npy` 形状 $[1600,17,16,12,6]$、划分文件 `train_idx.npy`／`val_idx.npy`／`test_idx.npy` 与候选特征 `candidate_features.npy`。
- $H_m,C_m$ 参数：以代理字段存在，位于 `event_metadata.jsonl` 与 `meta.json`，包括 `block_id`、`load_multipliers`、`fault_class`、`true_impedance`、`fault_delay_steps`；不存在名为 $H_m$ 或 $C_m$ 的字段。
- 模型信息：当前最佳响应预测模型为 `pi-response-full-20260920-1600-seed342-v2` 的 teacher 变体；输入为部署可见观测、拓扑、候选物理描述与掩码，输出为整族候选响应，loss 为节点归一化掩码 MSE；该变体在训练期额外使用真实阻抗，但其学生前向不读取真实阻抗或真实位置。
- 预测指标：存在。teacher 变体测试集 `response_distance_student = 0.0076749367`（均方口径逐元素均值），本报告独立复算得到 $0.0076749367$，与记录逐位一致。
- 候选级误差：存在（`i2_candidate_metrics.csv`），但仅在 I2 全连接 baseline 上产出，未在 teacher 变体上产出。
- 排序指标：存在（Top-1、Top-3、平均真实排名、`hardest_negative_consistency`），但不存在候选间差分响应误差与排序保持类指标（如逐事件候选间距离剖面的秩相关）。
- 输入条件消融：部分存在。既有 teacher 与 student 变体的差异是“是否在训练期使用真实阻抗”，只能部分反映特权条件的作用；不存在以 $(H_m,C_m)$ 或候选位置为输入的对照实验。

## 4. 基于既有产物的只读测量

本节全部测量为只读复算，不训练、不写入任何 `output/` 产物。所用模型为既有 `checkpoint/pi-response/pi-response-full-20260920-1600-seed342-v2/teacher.pt` 的学生前向，所用数据为 `paired-v1-ieee13-1600-seed342` 的测试划分 240 事件；距离一律按正式 $d_S$ 实现（节点—特征权重 $1/(s^2+10^{-8})$，分母为掩码元素数）计算，并逐处标注所用口径。

### 4.1 数据资格事实

- 事实响应与真实候选响应的配对严格成立：$d_S(X_m,S^{CF}_{m,K^{true}_m})$ 的中位数为 $0.0$，最大值为 $1.8947806286936004\times10^{-14}$。
- 候选掩码与节点掩码全为 1，$|\mathcal K_m|=17$ 对全部事件成立。
- 数据集按 400 个 block、每 block 4 个事件组织，每 block 内 `true_location` 互不相同，且 block 内 `fault_class` 与 `true_impedance` 亦随事件改变（不存在“同一 $(H_m,C_m)$ 下只改变真实位置”的事件对）。

### 4.2 族级误差的水平

- 学生前向在测试集上的逐元素均方族误差：均值 $7.674937\times10^{-3}$，中位数 $1.155938\times10^{-3}$，$p90$ $2.795002\times10^{-3}$。
- 同一数据上，与事件无关的常数族基线（17 项参数，取训练集均值族）：均值 $9.673326\times10^{-3}$，中位数 $1.368622\times10^{-3}$。I2 全连接 baseline 的测试集族误差中位数为 $3.184367\times10^{-2}$（开方口径），即 $1.014020\times10^{-3}$（均方口径）。
- 均值与中位数相差约 6.6 倍，说明族级误差的均值由少数离群事件主导，任何以均值为主的比较都必须同时报告中位数。

### 4.3 候选级误差的形状

- I2 baseline 的逐候选测试集误差：`mean_dS` 的均值 $2.210\times10^{-3}$、最大与最小之比 $7.32$；`median_dS` 的均值 $1.022\times10^{-3}$、最大与最小之比 $1.39$。
- 学生前向的逐候选 RMSE 同样呈现该形状：候选 0 为 $0.195241$，其余候选在 $0.060627$ 至 $0.095447$ 之间，正常候选为 $0.061589$。
- 结论：均值口径下的候选间差异由离群事件主导，而非候选本身系统性地更难。

### 4.4 候选间结构保真度

在测试集上只使用预测族与真值族本身（不使用 $X_m$）计算逐事件的候选间距离剖面，再比较两者。

- 候选间距离剖面的变异系数（开方口径）：真值中位数 $0.1081$，预测中位数 $0.6836$，预测与真值之比的中位数为 $6.3341$。
- 剖面对齐相关系数：均值 $0.4453$，中位数 $0.4234$，负值比例为 $0.0250$。
- 候选方向能量比（预测的候选相关分量范数与真值之比）：均值 $0.4668$，中位数 $0.4879$；候选方向余弦：均值 $0.2340$，中位数 $0.1788$。
- 结论：模型给出的候选族在形状上与真值族有正相关但幅度减半，且叠加了约 6 倍于真值的、与候选无关的抖动。这说明候选间结构被部分保留、部分被噪声化。

### 4.5 判别间隔：误差损失的位置

以 $X_m$ 对每个候选的预测族评分 $R_{m,k}=d_S(X_m,\widehat S^{CF}_{m,k})$，并与用真值族计算的同一评分对照。

- 真值族：真实候选中位评分 $0.0$，最近负候选中位评分 $1.145692\times10^{-3}$，间隔中位数 $1.145692\times10^{-3}$，间隔为负的比例 $0.000$。
- 预测族：真实候选中位评分 $1.073509\times10^{-3}$，最近负候选中位评分 $1.017572\times10^{-3}$，间隔中位数 $-3.536527\times10^{-5}$，间隔为负的比例 $0.804$。
- 间隔之比（预测与真值）中位数为 $0.0075$。
- 分离“真实候选自身的重建误差”与“其他候选的重建误差”：真实候选的均方评分均值为 $4.020087\times10^{-3}$（对应 RMSE $0.063404$），而逐候选均值口径下的整体误差为 $7.674937\times10^{-3}$，即模型在真实候选上确实优于平均，但其优势幅度远小于真值族所提供的间隔。

### 4.6 给定 $X$ 的族条件方差上界

在训练集 1120 事件内为每个事件寻找输入最近邻（按正式 $d_S$ 的展平距离），并在“距离不超过最近邻距离固定倍数”的邻域内测量真值族的离散度。

- 训练集内最近邻输入距离：中位数 $3.189876\times10^{-2}$，$p90$ $3.894067\times10^{-2}$。
- 邻域取最近邻距离的 $1.05$ 倍（每个事件平均 $1.782060$ 个邻居）：族离散度均值 $1.076343\times10^{-3}$，中位数 $5.780411\times10^{-4}$。
- 邻域取 $1.5$ 倍（邻居数中位数 $496$）：族离散度均值 $1.864438\times10^{-3}$，中位数 $1.694477\times10^{-3}$。
- 对照：学生前向的测试集族误差中位数 $1.155938\times10^{-3}$。
- 结论：模型的测试集族误差中位数已经低于“$X$ 近邻对之间”的族离散度中位数，且远低于 $1.5$ 倍邻域口径下的离散度。由于近邻对的族离散度是给定 $X$ 时族条件方差的上界而非下界，这一比较只能作为方向性证据，但它不支持“族级误差主要来自 $X$ 未提供足够状态信息”这一解释。

### 4.7 事实响应 $X$ 与反事实响应族的变异来源

- $X$ 相对全局均值的平均 $d_S$ 为 $5.131110\times10^{-3}$。
- 按 `block_id`（$H$ 相同）分组，组内平均 $d_S$ 为 $3.569600\times10^{-3}$，占全局 $0.6957$。
- 按 `true_location` 分组，组内为 $4.733561\times10^{-3}$，占全局 $0.9225$；按 `fault_class` 分组为 $4.968870\times10^{-3}$，占 $0.9684$；按阻抗四分位分组为 $4.895284\times10^{-3}$，占 $0.9540$。
- 按 `block_id` 与 `fault_class` 联合分组，组内降为 $1.072452\times10^{-3}$，占全局 $0.2090$。
- 对真实响应族，固定候选后按 `true_location` 分组的组间占比仅 $0.0078$ 至 $0.0092$，即在同一候选假设下，事件间响应族的差异几乎全部来自 $(H_m,C_m)$ 而非真实位置。
- 结论：位置与运行条件对 $X$ 的作用是耦合的，无法把 $X$ 干净地拆成“位置分量”和“运行条件分量”；而在反事实响应族一侧，同一候选下的族差异几乎只由 $(H_m,C_m)$ 决定。

### 4.8 真值位置在 $X$ 上的可分性

- 按 `true_location` 的最近质心分类，测试集位置命中率为 $0.1500$（随机基线 $0.0625$）。
- 逐真实位置的命中率为：母线 0、3、5、8、12、14 为 $0.0$，其余在 $0.105$ 至 $0.400$ 之间。
- 结论：$X$ 中包含位置信息但远不可分；结合 4.6，不能把低 Top-1 简单归因于“$X$ 不含位置信息”，也不能归因于“$X$ 的状态信息不足”。

## 5. 第一部分：已有实验是否足以判断 $E_{state}$ 与 $E_{candidate}$

不足以完成文稿要求的正式分解，但足以否定其中一种解释。分述如下。

- 无法直接完成的原因：$U_m=(H_m,C_m)$ 在数据中不可观测，其定义依赖一个未指定的提取算子；没有该算子，$E_{state}$ 没有数值定义。文稿把 $E_{state}$ 描述为“无法正确提取事件共享状态”，但提取器与 $U$ 的坐标同时未知，因而该量在现有实验设计下不可识别。
- 足以否定的解释：“误差主要来自状态提取错误，导致所有候选响应存在系统偏移”。实测表明与候选无关的分量在未加权均值口径下占族级总误差的 $0.3444$，在加权均值口径下占 $0.0064$，两种口径都不支持“主要由系统偏移构成”；真正的损失在候选间判别：真实间隔中位数 $1.145692\times10^{-3}$，模型间隔中位数 $8.238770\times10^{-6}$，$80.4\%$ 的事件间隔为负。
- 需要同时注意的一个逻辑限制：即使后续 oracle 状态实验把族级误差降到远低于当前水平，也只能说明“族级水平分量”可由状态改善，不能推出“候选间判别错误也来自状态”。要判定判别瓶颈的归属，必须单独检查候选方向上的保真度，而这正是现有记录中缺失的部分。
- 另需注意：现有 I1 与 I2 结果是关于 $X\to\mathcal S^{CF}$ 的整体可辨识性与可学习性，不构成 $E_{state}$ 与 $E_{candidate}$ 的分解。I1 的机械标签为 SUPPORT（近邻 $X$ 对应近邻族），I2 的机械标签为 NO_SUPPORT（R_test $=0.8728643924355792$，未达 $0.70$ 支持门），总体标签为 LOCAL_SUPPORT_LEARNING_UNRESOLVED。

## 6. 第二部分：缺少的证据

按重要性排列。

1. 缺少以真实生成条件为输入的对照实验。现有实验里只有“训练期是否使用真实阻抗”这一个特权条件对照，没有以 $(H_m,C_m)$ 整体为输入的对照，也没有以真实故障位置为输入的对照。
2. 缺少“在已知 $(H_m,C_m)$ 时，候选生成还能达到多好”的量化下界。现有条件均值类基线的测量显示：按 `fault_class` 分组的常数族基线在测试集上的族误差中位数为 $1.425577\times10^{-3}$，按 `(K_true, fault_class)` 分组为 $1.608290\times10^{-3}$，按 `block_id` 与 `fault_class` 联合分组与常数族相同（$1.368622\times10^{-3}$），均未优于常数族。这些分组因样本稀疏而不可用，但它说明“候选生成可达下界”目前完全空白。
3. 缺少判别层面的指标。现有记录只有 Top-1、Top-3、平均真实排名与 `hardest_negative_consistency`，没有候选间差分响应误差 $d(\Delta\hat S,\Delta S)$、逐事件候选间距离剖面的秩相关、pairwise ordering accuracy 或逐真实位置的命中分布。
4. 缺少带离群处理的误差报告。族级误差的均值与中位数相差约 6.6 倍，候选级 `mean_dS` 的最大最小之比为 $7.32$，因此只报均值会把结论交给少数事件。
5. 缺少逐候选级误差在“当前最佳模型”上的产出。现有 `i2_candidate_metrics.csv` 属于 I2 全连接 baseline，不是 teacher 变体，也不是任何具备候选条件解码结构的模型。

## 7. 第三部分：最小新增实验

以下三项按优先级排列，均只需使用既有 paired-v1 数据与既有模型与训练流程，不引入新数据生成。

### Priority 1：条件化候选生成上界（对应文稿实验 B 与实验 C 的合并与修正）

- 目的：量化“若 $(H_m,C_m)$ 完全已知，候选响应族还能预测到多好”，从而给出 $E_{candidate}$ 的上界。
- 输入：`block_id` 或 `load_multipliers`、`fault_class`、`true_impedance`、`fault_delay_steps` 与候选身份 $k$；不输入 $X_m$，也不输入 $K^{true}_m$。
- 输出：整族候选响应。
- 同时训练一个以 $K^{true}_m$ 为额外输入的对照臂，并把两者之差记为“真实位置信息的贡献”，避免把 $K^{true}$ 的信息误记为 $(H_m,C_m)$ 的作用。
- 判定：若该上界与当前 teacher 变体的族误差同量级（均方口径均值约 $7.7\times10^{-3}$，中位数约 $1.2\times10^{-3}$），则候选生成本身就是瓶颈，设计共享状态表示 $U$ 不会改善判别；若该上界显著更低，则瓶颈在“观测到条件”的这一段，才轮到 $X\to U$ 的设计讨论。

### Priority 2：候选间结构指标补齐（对应文稿实验 A 与实验 D）

- 目的：把“候选间判别损失”量化成可比较的指标，并消除离群事件对结论的支配。
- 指标：逐事件候选间距离剖面的秩相关（Spearman）与对齐相关系数；候选方向能量比与余弦；$d(\Delta\hat S,\Delta S)$ 的逐事件分布；pairwise ordering accuracy；逐真实位置的 Top-1 与平均排名；全部指标同时给出中位数、$p90$ 与去掉最差 $5\%$ 事件后的结果。
- 数据来源：既有 checkpoint 的学生前向输出加既有真值族，不需要新数据，也不需要训练。
- 判定：若判别类指标在真实候选上接近随机基线而族级误差已接近 4.6 的上界，则误差来源判定为候选生成，而非状态提取。

### Priority 3：状态信息可用性上界（对应文稿实验 B 的“状态是否可从 $X$ 恢复”）

- 目的：判断 $X$ 是否含有恢复 $(H_m,C_m)$ 的足够信息，而不是先假设需要显式 $U$。
- 做法：以代理条件为标签，训练 $X\to$ 条件 的探针（`block_id` 或 `load_multipliers` 回归、`fault_class` 分类、`true_impedance` 回归），报告探针在测试集上的误差，并与“条件对响应族的实际影响幅度”对照。
- 判定：若探针能把条件恢复到很小的误差，而下游族误差仍然很大，则“状态提取错误”不是瓶颈；若探针本身误差很大，则说明 $X$ 与条件之间存在不可消除的耦合，此时才需要讨论 $X\to U$ 的可辨识性，且必须先说明 $U$ 的定义与提取算子。

## 8. 第四部分：结果判断

按现有证据，判定落在该文稿的“情况 C：两者都有”与“情况 B：候选生成错误”之间，且明确排除“情况 A：状态提取错误”作为主要来源。理由如下。

- 排除情况 A 的直接证据：候选无关分量在两种口径下分别占 $0.3444$ 与 $0.0064$，即族级系统偏移不占主导；而候选间间隔从真值的 $1.145692\times10^{-3}$ 压缩到 $8.238770\times10^{-6}$（比值 $0.0075$），且 $80.4\%$ 的事件间隔为负。系统偏移不是主要损失，判别损失才是。
- 支持情况 B 的直接证据：候选间距离剖面的预测与真值之比中位数为 $6.3341$（刻画抖动），相关系数中位数 $0.4234$（刻画结构），候选方向能量比中位数 $0.4879$（刻画幅度减半）。这三点共同说明模型对 $(U_m,k)\to S^{CF}_{m,k}$ 这一段的候选对比度建模不足。
- 不能完全排除状态因素的原因：该文稿定义的 $E_{state}$ 在现有数据上不可识别，因此“状态因素完全不重要”这一结论同样没有证据。真正被排除的是“状态错误以族级系统偏移的形式主导总误差”这一具体机制。
- 因此下一步的可行方向是分两条并行推进：一是按 Priority 1 给出候选生成上界，确定 $(H_m,C_m,k)\to S$ 本身还剩多少误差；二是按 Priority 2 把判别类指标固定为后续所有实验的必报项。只有在 Priority 1 表明“条件已知时候选生成仍很差”之后，才应考虑对 $(U_m,k)\to S^{CF}_{m,k}$ 这一段设计共享状态表示与训练目标；在此之前直接设计 $X\to U\to S$ 结构缺乏证据支持。

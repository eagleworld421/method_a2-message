# Method-A2 `s0-lg-run3` 反事实监督候选评分消融与梯度分析报告

## 1. 实验目的与范围

本实验复用现有反事实评分路径，检验真实反事实响应构造的候选距离监督是否分别通过 `value` 与 `gap` 目标改善候选定位，并按照多损失梯度分析计划测量各目标的实际优化作用。实验只新增独立的分析模块、运行脚本和输出目录，不修改原有训练代码、原有数据和已有输出。

数据集为 `code/method-a2/data/s0-lg-run3/`，沿用其训练、验证和测试划分、候选掩码、事实观测和真实反事实响应族。候选数为 16 个故障位置，训练 200 轮，批大小 64，学习率 0.001，温度 1.0，随机种子 342，设备为 CPU。距离尺度由训练集非零真实距离中位数确定，为 `2.4339593074×10^-4`；间距阈值为 `0.0060236049`（已按该距离尺度归一化）。

## 2. 损失项与消融配置

反事实评分路径包含四个独立目标：

- `family`：预测反事实响应族与真实响应族之间的掩码 Smooth L1 重构损失，权重为 0.1；
- `list`：由真实反事实距离构造软候选分布的列表级 KL，权重为 1.0；
- `value`：评分值回归归一化真实距离，权重为 1.0；
- `gap`：在真实候选间距达到阈值时回归评分差与真实距离差，权重为 1.0。

四组配置为：

- `base`：`family + list`；
- `value`：`family + list + value`；
- `gap`：`family + list + gap`；
- `both`：`family + list + value + gap`。

梯度分析对每个目标先计算实际加权梯度，再按共享编码器、响应解码器和评分头分别统计梯度范数、范数占比、目标间余弦相似度和对合成梯度的投影。被消融目标仍被计算用于诊断，但其实际权重置零，因此其加权梯度应为零。

## 3. Top-K 消融结果

四组配置均使用验证集 Top-1 选择最佳轮次后，在同一测试集上评估。结果如下：

- `base`：最佳轮次 195，Top-1 为 41.67%，Top-3 为 71.88%，Top-5 为 90.63%，平均名次为 2.7188；
- `value`：最佳轮次 113，Top-1 为 23.96%，Top-3 为 54.17%，Top-5 为 73.96%，平均名次为 4.0521；
- `gap`：最佳轮次 44，Top-1 为 37.50%，Top-3 为 59.38%，Top-5 为 70.83%，平均名次为 4.0521；
- `both`：最佳轮次 32，Top-1 为 31.25%，Top-3 为 63.54%，Top-5 为 84.38%，平均名次为 3.3854。

相对 `base`，加入 `value` 使 Top-1、Top-3、Top-5 分别下降 17.71、17.71 和 16.67 个百分点；加入 `gap` 分别下降 4.17、12.50 和 19.79 个百分点；同时加入两项分别下降 10.42、8.33 和 6.25 个百分点。因此，当前实验不支持把 `value` 或 `gap` 视为可以直接叠加而不改变定位行为的辅助项。`base` 的列表监督已经在评分头上提供了直接的真实距离排序方向，新增绝对值与间距回归会改变该方向的优化平衡。

## 4. 梯度范数、占比与方向

### 4.1 `base`

在共享编码器上，`list` 的加权梯度范数占比由第 1 轮的 98.10% 上升到第 100 轮的 99.96% 和第 200 轮的 99.97%；`family` 的占比由 1.90% 降至 0.03%。两者在第 1、100、200 轮的余弦相似度分别为 0.299、0.014 和 0.099，说明后期共享表示几乎完全由列表评分目标驱动，但两个目标的方向并非稳定同向。

在评分头上，`list` 占全部有效梯度的 100%，因为 `family` 只经过响应解码器，不直接依赖评分头。在响应解码器上，只有 `family` 有非零梯度。该配置因此清楚地分离了“响应重构路径”和“候选评分路径”。

### 4.2 `value`

在共享编码器上，`value` 的梯度占比由第 1 轮的 41.62% 增至第 100 轮的 69.26% 和第 200 轮的 83.20%；对应的总梯度投影分别为 36.43%、71.24% 和 85.03%。在评分头上，`value` 占比由 46.32% 增至 62.94% 和 69.49%，投影由 45.84% 增至 66.34% 和 73.70%。

这表明 `value` 并非只校准评分数值，它会逐步重定向共享编码器和评分头的主优化方向。第 200 轮共享编码器上的 `list` 与 `value` 余弦为 -0.006，评分头上为 0.814；因此在评分头局部两者仍大体同向，但经过共享表示和候选条件交互后，最终没有转化为更好的定位 Top-K。

### 4.3 `gap`

在共享编码器上，`gap` 的梯度占比由第 1 轮的 46.99% 增至第 100 轮的 65.91% 和第 200 轮的 83.51%；第 200 轮对合成梯度的投影为 84.23%。在评分头上，`gap` 占比由 44.31% 增至 60.65% 和 75.18%，第 200 轮投影为 75.96%。

第 100 和 200 轮评分头上的 `list` 与 `gap` 余弦分别为 0.934 和 0.924，说明两者在评分头局部总体同向，但 `gap` 的绝对梯度更大。共享编码器第 200 轮的余弦为 -0.133，说明经过共享特征传播后存在轻微冲突。该配置 Top-5 降幅最大，表明间距回归没有稳定地改善候选族的整体排序。

### 4.4 `both`

同时加入两项后，第 200 轮共享编码器的梯度占比为：`list` 7.79%、`value` 40.93%、`gap` 51.29%；对应投影为 4.29%、40.22% 和 55.48%。评分头的梯度占比为：`list` 15.74%、`value` 39.71%、`gap` 44.55%，投影为 10.28%、42.45% 和 47.27%。`value` 与 `gap` 的共享编码器余弦由第 1 轮的 0.886 降至第 200 轮的 0.673，仍同向但不再等价；两项合并后几乎完全取代了 `list` 对共享表示的直接作用。

## 5. 真实距离间距与评价口径

测试集真实候选距离的中位相邻间距为 `1.585355×10^-5`，约为距离尺度的 6.51%。该间距相对于评分和响应重构的数值范围较小，导致 `gap` 目标对微小差异非常敏感。当前报告同时保留 Spearman 相关和严格全序一致率：四组配置的评分—真实距离 Spearman 分别为 `0.8816`、`0.8795`、`0.7996` 和 `0.8869`（顺序为 `base`、`value`、`gap`、`both`），但四组严格全序一致率均为 0。严格全序要求所有 16 个候选的排序完全一致，受近等距候选和并列影响过于苛刻，因此不应单独用它判断评分是否具有物理排序能力。

预测反事实响应距离的 Spearman 在 `base` 中为 0.7775，在 `value`、`gap`、`both` 中分别为 0.5899、0.5322 和 0.5753。该结果说明候选评分与真实反事实距离的相关性不能被预测响应距离完全替代；新增 `value` 和 `gap` 也没有自动提升预测响应距离的候选结构保真度。

## 6. 结论与下一步判据

本次消融支持以下判断：

- `list` 是当前候选评分路径的主要定位监督，`base` 在四组配置中取得最高 Top-1、Top-3 和 Top-5；
- `family` 主要作用于响应解码器，对评分头没有直接梯度；
- `value` 和 `gap` 确实把真实反事实物理距离传入评分头及共享编码器，但在当前未重新标定的单位权重下，它们后期主导梯度，却降低了定位性能；
- `value` 与 `gap` 不能简单解释为互补的两个小修正项；它们改变了评分尺度和共享表示的训练方向，必须结合目标尺度、真实间距分布和验证集定位指标共同调节；
- 真实候选间距较小是当前新增间距监督的明确风险来源，不能仅凭训练损失下降判断其有益。

本实验没有改变 `value` 和 `gap` 的定义或权重，也没有引入新的损失项。下一步若继续优化，应优先做固定数据划分下的权重扫描和间距阈值敏感性分析，并继续保留梯度投影与 Top-K 作为联合判据。

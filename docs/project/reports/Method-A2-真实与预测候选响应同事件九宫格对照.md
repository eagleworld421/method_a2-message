# 真实与预测候选响应同事件九宫格对照

## 对照定义与案例身份

本次固定[真实候选响应检验](Method-A2-真实候选响应差异与距离关系检验报告.md)中下降案例的三个事件、候选集合及位置距离。每行对应一个事件，三列依次为跳数、线路长度及无零序模态阻抗路径距离，横轴均除以对应全网直径。保持真实观测 $X_m=S_m(f)$ 作参照，仅替换候选响应：

$$D_m^{true}(f,k)=\frac{\|S_m(f)-S_m(k)\|_F^2}{NTC},\qquad D_m^{pred}(f,k)=\frac{\|S_m(f)-\widehat S_\theta(X_m,k)\|_F^2}{NTC}.$$

三个案例按原顺序为：A 第 17 族、数据行 647、真实母线 709（索引 1，训练集）；B 第 8 族、数据行 336、真实母线 734（索引 32，训练集）；A 第 38 族、数据行 1466、真实母线 732（索引 22，测试集）。不替换事件来满足测试集要求，因此本对照不是全部测试集的泛化评价。

## 预测与物理尺度

使用 `output/gref/ieee37-a-seed342-20261103/` 和 B 对应目录中的最佳检查点，设置 `eval` 并关闭梯度，仅将观测、拓扑及可见掩码传入模型；不重新训练。输出位于模型逐节点归一化坐标，需要先撤销该变换，再还原数据存储标准化：

$$\widehat Z_{n,t,c}=s_{n,c}\widehat R_{n,t,c}+\mu_{n,c},\qquad D_m^{pred}(f,k)=\frac1{NTC}\sum_{n,t,c}\sigma_c^2\left(\widehat Z_m(k)_{n,t,c}-Z_m(f)_{n,t,c}\right)^2.$$

其中 $s,\mu$ 为检查点配套的逐节点归一化参数，$\sigma_c$ 来自原数据 `feature_scaler.npz`。纵轴单位仍为 pu²，与 Oracle 主分析一致；图中纵轴显示范围根据预测数值调整，未沿用会截断预测值的 Oracle 范围。该物理度量与训练坐标中直接计算的部署评分存在通道权重差异。

## 结果

下表的相关均排除真实候选，对全部 37 个错误候选计算。

| 案例 | 跳数 ρ，真实→预测 | 长度 ρ，真实→预测 | 阻抗 ρ，真实→预测 |
|---|---:|---:|---:|
| A，17 族，709，训练 | 0.333 → −0.219 | 0.578 → 0.056 | 0.530 → −0.075 |
| B，8 族，734，训练 | 0.670 → 0.577 | 0.713 → 0.613 | 0.702 → 0.583 |
| A，38 族，732，测试 | 0.657 → 0.368 | 0.747 → 0.442 | 0.751 → 0.347 |

三个案例中，物理差异与模型原坐标评分均将真实故障点排在首位，但距离排序趋势均有减弱。真实故障候选的预测差异分别为 0.05684083、0.08173781、0.07656720 pu²，并不为零；故红色星号按实际预测差异放置。

这些案例说明“真实候选仍为最低”与“错误候选之间的距离结构被完整保留”并不等价。仅凭三个已选案例不能推断全测试集的结构保持程度。

## 图件与验证

最终产物位于 `code/method-a2/output/gref/paired-oracle-prediction-20261103/`，脚本为 `scripts/plot_predicted_response_cases.py`。

- `predicted-response-detail.png` 与原主体放大图采用相同候选展示集合，不展示 775；相关系数及分类阈值仍按全部 38 个故障候选计算。各子图标注真实与预测相关系数，点旁数字仍为候选索引。
- `predicted-response-full.png` 保留全部候选。两种图均提供 SVG；灰、橙、红线分别对应外向增长、平台和下降。平台仍采用 1% 事件范围与浮点容差的同一规则，根据预测值重新计算阈值。
- `analysis.json` 记录事件身份、划分、两种评分的最小值候选、逐候选真实与预测差异、相关、参数文件哈希及验证结果。
- `candidate-values.csv` 包含全部 114 个“事件—候选”配对；`predicted-responses.npz` 保存三次推理的候选响应及真实参照，坐标在键名中明确标示。
- `gallery.html` 提供图件入口，`figures-and-data.zip` 包含图件与数值。

逐候选 Oracle 差异已从原数据独立复算并与既有结果核对一致；测试案例新推理响应与既有预测的最大绝对差为 $2.8610\times10^{-6}$（模型坐标），通过预设浮点近似检查。推理前后参数逐元素不变，检查点、归一化和划分文件哈希不变。附加解析数值检查验证了两层尺度撤销公式，图件经可视化核验。

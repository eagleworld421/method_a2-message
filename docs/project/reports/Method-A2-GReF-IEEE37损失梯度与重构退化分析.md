# GReF IEEE37 损失梯度与重构退化分析

## 1. 问题口径与复核范围

本分析承接[首轮训练测试报告](Method-A2-GReF-IEEE37首轮训练测试报告.md)，执行日期为 2026-11-03。当前目标仅包含

$$L=L_{loc}+0.1L_{family}.$$

`rank`、`list`、`pair`、`value` 与 `gap` 未参与当前优化，物理教师与门控权重停止梯度。

相对旧独立评分头，A 测试 Top-1 由 98.68% 降至 97.81%，下降 0.88 个百分点；B 由 93.86% 降至 89.04%，下降 4.82 个百分点。因此 A 的定位变化较小，B 的下降不能视为完全不变。相对旧模型在 GReF 坐标中的响应距离评分，定位则分别由 16.23% 与 9.21% 提高至 97.81% 与 89.04%。两类比较不可混淆。

重构误差的明显增大是相对旧模型而言，不代表 GReF 训练过程中持续单调上升。例如 A 第 1、100、161、200 轮验证重构损失分别约为 0.5811、0.4081、0.5040、0.3928；B 第 1、190、200 轮分别约为 0.5552、0.5282、0.4702。以 Top-1 优先选模也不保证选中重构最好的轮次。

测量按[多损失梯度贡献分析计划](../plans/Method-A2-多损失梯度贡献分析计划.md)复用既有 `gradient_report`：

- 固定 A 第 161 轮与 B 第 190 轮最佳模型，覆盖各自全部 2280 条最终训练样本，包括正常样本。
- 种子 342 固定打乱顺序，批大小 64，共 36 个混合批次；两项梯度来自同一次前向与相同掩码。
- 分别关闭与启用 Dropout 测量，不执行优化器更新，检查模型状态逐元素不变。
- 使用 $g_l=\nabla L_{loc}$ 与 $g_f=\nabla(0.1L_{family})$，主要统计量为逐批结果的中位数。
- 模块分别为共享编码器和响应解码器，当前不存在独立评分头。
- 这是固定最佳模型的局部复核，不是训练历史轨迹。未保存 Adam 状态，不能把原始梯度解释为实际参数位移。

## 2. 各损失项的优化强度

关闭 Dropout 的完整训练批次结果如下。范数比是逐批范数比的中位数，不是两个中位范数直接相除。

- A 编码器：定位梯度范数中位数 10.4864，加权重构梯度 0.03590；定位约强 292.32 倍，定位梯度强度占比中位数为 99.66%。
- A 解码器：定位梯度范数中位数 0.21487，加权重构梯度 0.03458；定位约强 6.26 倍，定位梯度强度占比中位数为 86.23%。
- B 编码器：定位梯度范数中位数 43.7253，加权重构梯度 0.08376；定位约强 537.64 倍，定位梯度强度占比中位数为 99.81%。
- B 解码器：定位梯度范数中位数 0.48096，加权重构梯度 0.05982；定位约强 8.37 倍，定位梯度强度占比中位数为 89.33%。

启用 Dropout 后，A 编码器与解码器的范数比分别约为 296.69 与 10.08；B 分别约为 538.38 与 8.47。定位主导的结论保持一致。

这些占比仅表示当前参数模块上的加权梯度强度，不能表述为准确率贡献率或 Adam 更新份额。

## 3. 方向冲突与对重构的局部作用

评价模式下，A 解码器两项梯度余弦中位数为 -0.41795，97.22% 批次余弦为负；B 中位数为 -0.27100，91.67% 批次为负。编码器两项梯度的余弦中位数分别约为 0.00890 与 0.00188，接近正交，因此不能把两个模块都解释为持续强冲突。

设 $g_\Sigma=g_l+g_f$，重构项的合成梯度投影为

$$P_f=\frac{g_f^\top g_\Sigma}{\|g_\Sigma\|^2}.$$

若仅沿该模块的合成负梯度作足够小的梯度下降步，则重构目标的一阶变化为 $-\eta g_f^\top g_\Sigma$。因此 $P_f<0$ 表示该模块的局部合成方向会增大重构目标。

- A 解码器 $P_f$ 中位数为 -0.03310，88.89% 批次为负。
- B 解码器 $P_f$ 中位数为 -0.01578，75.00% 批次为负。
- 启用 Dropout 后，对应负投影比例为 77.78% 与 75.00%。

这比单纯比较梯度范数更直接地表明，重构梯度不仅较弱，在多数解码器批次上还在抵消定位主导方向。它仍不能直接推出完整 Adam 更新后的重构必然上升，因为上述结论是模块局部、原始梯度和一阶近似口径。

## 4. 为何较大的重构误差可以与较高定位准确率并存

部署评分为 $e_k=D(X,\widehat S_k)$，定位监督为能量上的交叉熵。对有效故障事件有

$$\frac{\partial L_{loc}}{\partial e_{m,k}}=\frac{w_m}{\sum_jw_j+\eta}\frac{\mathbf1[k=y_m]-p_{m,k}}{T}.$$

因此当前目标将真实候选响应拉向观测，并将具有竞争概率的错误候选响应推离观测。错误候选的真实响应若原本接近观测，强定位监督便可能要求其产生超出真实物理差异的分离。重构目标则要求错误候选响应接近其对应的真实仿真响应，二者不保证同向。

定位项受 $1/T$ 缩放，重构项额外乘以 0.1；重构采用 Smooth L1，其大残差区梯度不继续随误差幅值线性增大。测试故障候选响应中，A 约 18.56%、B 约 37.07% 的元素已进入 Smooth L1 的线性区。上述因素共同说明，重构损失较大并不意味着其梯度能够压过定位项；实际强度应以第 2 节实测为准。

另一方面，对于逐事件的候选共有加性常数 $c_m$，有

$$\operatorname{softmax}(-(e_{m,k}+c_m)/T)=\operatorname{softmax}(-e_{m,k}/T).$$

因此交叉熵和候选顺序无法约束能量的候选共有加性分量。

在完整测试故障候选上，将响应误差按候选均值与候选中心化残差正交分解，A 的共有响应误差占总 MSE 约 90.09%，B 为 92.91%；对预测能量相对真实能量的误差作同类分解，共有能量误差分量分别占约 95.46% 和 94.21%。这解释了为何总体响应误差很大时，候选相对顺序仍可以较好。

需区分：共有响应偏移不一定保持距离排序，因为平方距离含交叉项；严格不改变交叉熵和排序的是共有能量加性常数。这里的响应分解与能量分解是不同统计量。

## 5. 完全正确响应的目标函数反例

对相同的 36 个训练批次，将预测响应直接替换为真实响应，使重构项精确为零，保留同一温度、教师门控和归约方式，计算输出空间参考目标。

- A 当前模型的平均批次定位项约为 0.14999，加权重构项约为 0.02993，总目标为 0.17992；完全正确响应的总目标反而约为 1.09238。
- B 当前模型的平均批次定位项约为 0.13244，加权重构项约为 0.03441，总目标为 0.16684；完全正确响应的总目标反而约为 0.67245。
- 两组均在全部 36 个批次上出现当前模型总目标低于完全正确响应的情况。

这提供了当前目标函数在输出空间中不以物理真值为最优的实测反例：当真实候选间隔较小、温度固定时，完全正确的响应仍可能对应较高熵的候选分布，而 one-hot 定位交叉熵要求更确定的首位判断。当前重构权重不足以抵消通过扭曲响应降低定位损失的收益。

该对照不证明精确真实响应映射可由当前网络表达，也不独立证明训练全程采用了某种特定机制；但它排除了“只因重构损失下降较慢，目标本身仍充分偏好精确物理响应”这一解释。单纯机械平衡梯度范数也不能自动解决两个目标的几何错配。

## 6. 证据、验证与后续边界

- 原始结果位于 `code/method-a2/output/gref/gradient-analysis-20261103/`，包括 `analysis-a.json`、`analysis-b.json`、`summary.json` 与 `perfect_response_reference.json`。
- `analysis-*.json` 保存全部批次索引、原始范数、RMS、范数占比、余弦、投影与两个 Dropout 模式；`perfect_response_reference.json` 保存真实响应替换对照的逐批结果。
- 可复用入口为 `code/method-a2/scripts/analyze_gref_gradients.py`，复用既有 `src/loss_ablation/analysis.py`，不修改训练入口或已训练权重。真实响应替换对照另按第 5 节定义计算。
- 分析已执行完整两组各 36 批次、两种模式；合成投影和为 1、响应误差正交分解恒等式及模型状态不变检查均通过。既有梯度工具的 2 项接口测试通过。
- 当前证据最支持的解释为：定位监督在实际梯度上主导优化，其与物理重构在多数解码器批次上冲突，同时定位目标对部分共有误差不敏感，且当前目标函数可偏好失真响应。
- 该结论不能量化每个机制对最终泛化性能的独立因果贡献。权重、温度及重构保护的修正应在新的训练与验证侧受控实验中预登记，不能据本轮测试表现追加调参；本次未执行重新训练消融。

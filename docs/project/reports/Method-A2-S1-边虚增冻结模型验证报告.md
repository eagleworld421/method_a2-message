# Method-A2 S1 边虚增冻结模型验证报告

日期：2026-11-06

## 1. 实验目的

验证候选边全集表示、真实／观测拓扑分离和冻结 GReF 推理链路是否能够表示边虚增，并检查激活虚增边是否真正影响模型前向输出。本次验证不进行训练期拓扑增强，不重新训练模型。

## 2. 数据与配置

- 基础数据：`s0-ieee37-r0p01-20-loguniform`。
- 派生数据：`code/method-a2/data/s1-ieee37-parallel-edge-v1/`。
- 派生方式：复用原始物理响应、候选响应、划分和标准化统计，不重新运行 OpenDSS；在真实拓扑第一条无向边上增加一条属性复制的平行候选边。
- 真实拓扑：74 条有向边、37 条无向边。
- 候选全集：76 条有向边、38 条无向边。
- 虚增表示：新增边的 `edge_mask_true=0`；评估时将对应 `edge_mask_obs` 置为 1。
- 模型：冻结 `ieee37-a-seed342-20261103` GReF 检查点。
- 损失函数：标准 GReF 损失，即能量门控定位项与全候选响应重构项；运行配置使用 `energy_tolerance`、`temperature` 和 `lambda_family`，未启用三项损失模式。
- 测试事件：228 个。

## 3. 结果

干净观测和激活平行虚增边后的定位指标完全相同：

- Top-1：0.978070；
- Top-3：0.995614；
- Top-5：1.000000；
- 平均名次：1.035088。

输出差异审计显示，激活虚增边没有被静默忽略：

- 响应张量最大绝对差：0.103783；
- 候选分数最大绝对差：0.007700。

因此，本次单条属性复制平行边会改变冻结模型的中间响应和候选分数，但在 228 个测试事件上没有改变 Top-1、Top-3 或 Top-5 排序结果。

## 4. 结论

本次验证确认候选边全集、真实／观测掩码分离和冻结模型推理链路均可工作。标准 GReF 模型能够感知激活的平行虚增边，并改变响应与候选分数；在当前单条虚增边、属性复制和 IEEE37 测试集条件下，定位排序指标保持不变。因此，本结果支持继续开展边虚增场景验证，但不支持直接得出拓扑错误检测能力或训练期拓扑增强有效性的结论。

# Method-A2 GReF IEEE37 首轮训练与测试报告

## 1. 执行协议与数据

本轮按[首轮执行计划](../plans/Method-A2-GReF-IEEE37首轮训练测试执行计划.md)完成两套既有 IEEE37 数据集的训练和测试，方法定义见 [GReF 设计](../plans/Method-A2-GReF门控响应能量定位设计与实现.md)。执行日期为 2026-11-03，种子为 342，设备为 NVIDIA GeForce GTX 1660 SUPER。两组均使用批大小 64、学习率 0.001、重构权重 0.1，完成 200 轮训练。

- A 数据电阻范围为 0.01–20 Ω，B 为 10–100 Ω，均采用对数均匀抽样。
- 每组包含 40 个故障事件族、1520 条故障样本和 1216 条正常样本；故障候选为 38 个，另有一个正常候选。
- 最终划分为 28 个训练故障族加全部正常样本，共 2280 条；验证和测试各 6 个故障族、228 条样本，分组交集均为零。
- 正常候选参与重构，不进入故障定位排名；验证和测试不含正常样本，因此本轮不评价故障检测能力。
- 标准化仅拟合最终训练侧有效候选，逐节点逐通道统计，不再次除以旧数据标准差。

## 2. 数值容差与温度

容差仅根据最终训练侧的 float32 一个 ULP 扰动、仿射变换与规约舍入差异，以及 CPU/CUDA 间隔差异确定。

- A 容差为 `2.231209336901537e-6`，训练故障样本定位监督覆盖率为 98.97%；最终测试门控诊断覆盖率为 100%。
- B 容差为 `2.3069154875252437e-6`，训练故障样本定位监督覆盖率为 70.49%；最终测试门控诊断覆盖率为 69.30%。
- 每组对三个预登记温度分别训练 20 轮，仅在验证集选参。A 选择 `0.012815295718610287`，B 选择 `8.550644088245463e-5`。
- 两个最优温度均位于有限网格的较大端，不能解释为已经充分优化。选择完成后冻结配置，从头训练 200 轮，未使用测试结果追加调参。

上述容差仅反映干净 S0 数据的数值敏感性，不是传感器噪声标定或全部候选的认证误差上界。门控只影响训练损失，完整测试评价未筛除任何事件。

## 3. 定位结果与耗时

A 选中第 161 轮：

- 验证 Top-1/3/5 为 95.18%/98.68%/99.56%。
- 测试 Top-1 为 97.81%，正确 223/228；Top-3 为 99.56%，Top-5 为 100%。
- 测试真实候选名次分布为第 1 名 223 条、第 2 名 3 条、第 3 名 1 条、第 4 名 1 条；平均名次为 1.0351。
- 训练入口实测总耗时为 552.512 秒，包含训练侧归一化、审计、200 轮训练与验证、最终测试和写出，不包含温度预选。

B 选中第 190 轮：

- 验证 Top-1/3/5 为 85.09%/98.68%/100%。
- 测试 Top-1 为 89.04%，正确 203/228；Top-3 为 99.56%，Top-5 为 100%。
- 测试真实候选名次分布为第 1 名 203 条、第 2 名 23 条、第 3 名 1 条、第 5 名 1 条；平均名次为 1.1272。
- 训练入口实测总耗时为 553.864 秒，计时口径与 A 相同。

两组真实响应 Oracle Top-1 均为 100%。旧独立评分头测试 Top-1 分别为 98.68% 和 93.86%；GReF 本轮未超过该定位性能参照，其参数量为 37064，旧模型为 39209。

## 4. 同坐标响应比较与关键否定结果

为避免归一化口径混淆，将旧运行保存的观测、预测响应和目标响应统一变换至本轮 GReF 坐标，并确认测试索引与事实观测逐元素一致。旧模型仅进行离线响应距离重评分，未在新坐标下重新训练，因此以下比较不能单独归因为某一损失项的因果贡献。

- A：旧响应距离 Top-1 为 16.23%，GReF 为 97.81%；但旧模型全候选 Smooth L1 为 0.0371160，GReF 为 0.5008973，重构误差约增至 13.50 倍。真实候选响应 MSE 亦由约 0.07248 升至 1.14607。
- B：旧响应距离 Top-1 为 9.21%，GReF 为 89.04%；但旧模型全候选 Smooth L1 为 0.0187516，GReF 为 0.5023123，重构误差约增至 26.79 倍。

本轮证明响应能量上的定位监督能够训练出较高的候选排序准确率，但不能证明预测响应的物理重构更准确。两组重构均明显恶化，未通过设计中要求的重构质量保护条件，因此不能判定当前配置已实现兼顾定位与物理响应保真的方法改进。

## 5. 复算、结构审计与梯度诊断

- 保存预测的能量重算与指标文件 Top-K 一致；独立重算的重构损失与记录一致。
- 事实观测与真实候选目标逐元素差为零，训练、验证、测试故障族无交叉，源码摘要与运行配置记录一致。
- 两组在 64 条测试样本上通过候选同步置换检查，不存在可训练的自由评分头参数。
- 完整测试集的候选均值响应屏蔽使原始实现的 Top-1 降至约 3.07% 和 3.51%。有限精度规约会对数学并列能量产生微小差异，因此另保存单次能量求值后精确复制的并列参照，其稳定索引排序 Top-1 两组均为 1/38，即 2.63%；原始审计结果未被覆盖。
- 在最终检查点上，以种子 342 从训练故障事件抽取 32 条，在评价模式、CPU 上测量原始梯度，未更新参数。
- A 编码器上的定位梯度范数约为 34.00，加权重构梯度为 0.09769；解码器对应为 0.33949 和 0.06373，两目标解码器梯度余弦为 -0.23079。
- B 编码器上的定位梯度范数约为 168.59，加权重构梯度为 0.17192；解码器对应为 0.90322 和 0.11504，两目标解码器梯度余弦为 -0.02643。

该单批诊断支持定位目标在当前尺度下明显强于重构约束、且两目标存在局部方向冲突的解释，但不能据此独立证明训练全程的因果机制。未保存 Adam 状态，未测量实际预条件更新；本轮也未完成事实屏蔽和多种子机制验证。

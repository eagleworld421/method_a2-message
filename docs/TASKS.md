- 时间：任务开始 2026-09-23 / 分支创建沿用既有分支 / 合并待定
- 关键决策：判定落在设计文档三分支之外的新档位，按第 2.2 节"未定需报告逐维结果并指明哪些维度可恢复"补全为独立的 S2 未定分支，不强行归入"提取失败"或"瓶颈在表示之后"；数据集与权重未迁入本工作区，按设计文档第 0 节从 `method_a` 仓库读取并把实际路径、来源标识与权重 sha256 固化进 `config.json`；因本机 sklearn 1.0.2 与 scipy 1.13.1 不兼容，岭回归改用 lsqr（与 svd 系数最大差 1.1e-8）、多类逻辑回归改用 newton-cg（规格未指定 solver，较 lbfgs 快约 119 倍），两项取舍均写入产物；补跑浅层非线性 probe 后确认 S2 判定不随 probe 容量改变，但发现逐维结论在两种 probe 家族之间翻转，故规定逐维结果只作为"平均口径掩盖异质性"的证据、不据它给出哪些维度提取失败的结论；为长任务加入逐次拟合增量落盘、按 block 的子采样冒烟开关与不再持有非必要 probe 模型的内存约束。

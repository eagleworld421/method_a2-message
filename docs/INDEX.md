# 项目文档索引

## 检索顺序

当用户消息涉及多个文档主题时，按以下顺序检索：

1. `docs/TASKS.md`：任务、需求、版本和变更记录。
2. `docs/git-rules.md`：Git 规范、commit trailer、分支和提交流程。
3. `docs/project/`：已确认的项目目标、技术路线和设计决策。其中 `docs/project/plans/` 存放实验计划与设计类文档，`docs/project/reports/` 存放实验报告与结论文档，其余文档位于 `docs/project/` 根目录。
4. `docs/superpowers/`：Superpowers 设计说明和实施计划（目录按需创建）。

- `docs/project/plans/Method-A2-误差来源判定实验计划.md`：取代《Method-A2-反事实响应预测误差来源分析》的实验设计部分，重新制定“误差来自提取 $(H_m,C_m)$ 失败还是来自 $(H_m,C_m,k)\to S$ 映射失败”的判定实验。先用数据生成事实指出原计划不可判别的四处原因（三臂共享同一候选条件化解码路径、Experiment 2 与 3 输入相同、“状态”未含故障前工作点、继承不成立的加法分解），再把问题归约为两个互不依赖的判据：判据一（提取判据）在冻结表示上检验模型是否把 $(H_m,C_m)$ 装入表示，判据二（映射判据）在条件完全已知时检验映射是否可学。定义协议差值形式的归因量 $D_{state}=E_4-E_3$ 与 $D_{map}=E_5-E_{const}$，并给出 E0 基线复算、E1 判据一、E2 过拟合前置门、E3 冻结表示加 oracle 条件解码、E4 全 oracle 条件映射、E5 位置／故障条件／工作点三类归因分解、E6 输出侧条件敏感性检验的假设、可证伪预测、预先登记阈值与阶段门，以及算力预算、产物清单与不可证明的边界。当前仅为实验执行前的计划，不含实验结果。

- `docs/project/reports/Method-A2-误差来源公式核验与实验证据审计.md`：核验“误差来源定位”分析文稿的前提与公式，判定其物理事实与反事实生成记法、候选集合与 $d_S$ 定义、模型输入输出前提与既有文档和代码一致，但误差加法分解 $E_{total}=E_{state}+E_{candidate}$ 不是恒等式（实测逐事件交叉项最大 $0.2020$），候选集合归一记号应为 $|\mathcal K_m|$，量纲口径被混写，且“模型隐含完成 $X_m\to U_m$”与实现不符。记录基于既有 paired-v1 数据与既有 teacher checkpoint 的只读测量：候选无关分量在未加权与加权均值口径下分别占族级总误差 $0.3444$ 与 $0.0064$，真实候选间隔中位数 $1.145692\times10^{-3}$ 对模型间隔中位数 $8.238770\times10^{-6}$（比值 $0.0075$），$80.4\%$ 的测试事件间隔为负；模型测试集族误差中位数 $1.155938\times10^{-3}$ 低于训练集 $X$ 近邻对之间的族离散度中位数 $1.782060\times10^{-3}$。判定为现行证据足以排除“误差主要来自状态提取”这一机制，但不足以完成正式的 $E_{state}$ 与 $E_{candidate}$ 分解，并给出条件化候选生成上界、候选结构指标补齐与状态信息探针三项最小新增实验。含结论表述，不含新训练实验。

- `docs/project/reports/Method-A2-误差来源三组信息条件实验报告.md`：记录按上述计划执行的三组实验（运行标识 `esrun-20260922-error-source`）的完整结果。第 2 至 4 节记录统一划分与候选轴、22 维条件向量布局（15 个负荷乘子加故障类型单热、log1p 故障阻抗与故障时刻）、条件臂的冻结观测实现决策、$X$ 无关性校验（$0.000\times10^{0}$ 与 $2.608\times10^{-8}$）与条件置换探针（响应最大改变 $7.0718\times10^{-3}$ 至 $5.1594\times10^{-2}$）。第 5 至 7 节记录三层误差数据与判定：测试集族级 $d_S$ 均值 Experiment 1 为 $7.674937\times10^{-3}$、Experiment 2 为 $8.291738\times10^{-3}$、Experiment 3 为 $7.583605\times10^{-3}$，中位数分别为 $1.145166\times10^{-3}$、$2.027216\times10^{-3}$ 与 $1.546914\times10^{-3}$；相对训练集均值常数族基线（均值 $9.673326\times10^{-3}$、中位数 $1.289017\times10^{-3}$），两个条件臂在均值口径更优而在中位数口径更差；候选间距离剖面对齐相关系数三组几乎相同（$0.423$、$0.390$、$0.438$），候选方向能量比由 $0.488$ 降至 $0.281$ 与 $0.269$，候选无关偏移占比由 $0.344$ 升至 $0.437$ 与 $0.454$；定位 Top-1 分别为 $0.1625$、$0.1458$ 与 $0.2292$。判定为给出真实 $(H_m,C_m)$ 未降低族级误差也未改善候选间结构保真度，因此不支持“误差主要来自共享状态提取不足”。第 8 至 10 节记录产物清单、可核对项与边界限制。含结论表述。

## 检索约束

- 命中相关文档后，后续操作以文档内容为准，不得在未阅读的情况下自行修改相关内容。
- 若回答来自网络或模型通用知识而非项目文档，应主动说明尚未经过项目文档验证。
- 所有项目文档统一位于 `docs/`。

## 实验文档归档约定

- `docs/project/` 根目录存放研究目标与问题动机、技术路线与方案路线、项目入口与决策流程记录、当前状态记录，以及尚未归入以下两类的其他项目文档。
- `docs/project/plans/` 存放实验执行前形成的计划与设计类文档，包括实验流程与决策规程、实验与实现设计、符号与公式定义、数据契约与生成流程，以及指标与可辨识度规范。
- `docs/project/reports/` 存放实验执行后形成的结果与结论文档，包括正式结果摘要、实验执行结论，以及审计与复核分析报告。
- 判断新增文档应写入根目录、`plans/` 还是 `reports/` 时，以文档在实验执行前还是执行后产生为主要依据；无法判断时先请示确认，不得随意放置。
- `docs/superpowers/plans/` 存放 Superpowers 实施计划，不存放实验计划。
- 单次运行的原始产物及其 `report.md` 按 `code/method-a2/output/<experiment-id>/<run-id>/` 归档；`docs/project/reports/` 只存放汇总结论级实验报告，不复制逐样本结果。
- 文档在上述目录之间迁移时，必须同步更新本索引中的路径，以及文档正文与其他文档中的交叉引用。

## 迁移路径口径说明

- 本工作区由 `method_a` 仓库迁移得到，只迁入治理规范与 Method-A2 文档，未迁入业务代码、数据集、模型权重与运行产物。
- 迁移后的文档正文保留原有路径口径（形如 `code/method-a1/...`），未作改写；这些路径在本工作区内不解析，对应代码与产物仍位于 `method_a` 仓库的 `code/method-a1/` 下。
- 后续把 Method-A2 代码、数据与产物迁入本工作区时，统一归档至 `code/method-a2/` 的同名相对路径，并同步改写文档正文中的路径与本索引。

## 文档更新约束

- 新增或修改 Markdown 文档时，必须维护该文件开头的 HTML 摘要。
- 新增实验计划或实验报告时，必须写入 `docs/project/plans/` 或 `docs/project/reports/`，并同步更新本索引。
- 若文档新增、删除、迁移或改变触发关键词、文件路径或检索顺序，必须同步更新本索引。
- 规则文档和任务记录使用列表或段落，不使用表格。
